# Constructive Programming Learning Framework (CPLF)
**Version:** 1.0 (Frozen)

## Manifesto

> Belajar pemrograman bukanlah proses menghafal sintaks, melainkan proses membangun cara berpikir untuk memahami masalah dan merancang solusi yang bermanfaat. Bahasa pemrograman hanyalah media; tujuan utamanya adalah membentuk problem solver yang mampu terus belajar di tengah perubahan teknologi.

---

# Visi

Membentuk pembelajar sepanjang hayat yang mampu berpikir logis, kritis, sistematis, dan ilmiah, serta memanfaatkan teknologi—termasuk AI—secara bertanggung jawab untuk menyelesaikan masalah nyata.

# Misi

- Mindset didahulukan daripada sintaks.
- Konsep lahir dari kebutuhan.
- Error dipandang sebagai umpan balik.
- Setiap materi menghasilkan karya.
- Pemrograman digunakan sebagai media melatih reasoning.

---

# Pilar Filosofi

1. Programming is Thinking.
2. Learning by Constructing.
3. Every Concept Solves a Problem.
4. Error is Feedback.
5. Build Before Theory.
6. Growth Over Competition.
7. Project is Evidence.
8. Technology Agnostic Learning.

---

# Hakikat Berpikir

Berpikir adalah proses memahami masalah, menghubungkan fakta, menyusun hipotesis, menguji solusi, lalu memilih solusi yang paling masuk akal berdasarkan bukti yang dimiliki.

Reasoning mencakup:
- Deduktif
- Induktif
- Analogi
- Analisis sebab-akibat
- Hipotesis dan validasi

---

# CPLF Learning Cycle

Real World
→ Masalah
→ Rasa Penasaran
→ Eksplorasi
→ Error
→ Diskusi
→ Pemahaman
→ Konsep
→ Latihan
→ Project
→ Refleksi

---

# Lapisan Pembelajaran (selaras Framework)

```text
Identity → Prinsip Bernalar → Mindset → Mental Model → Skill → Tool
```

# Prioritas Pembelajaran

1. Identity & Prinsip Bernalar (klarifikasi)
2. Mindset & Mental Model
3. Skill (lewat practice spiral)
4. Tool (media yang boleh berganti)
5. Character dibangun sepanjang proses — bukan identity foreclosure profesi

---

# Budaya Kelas

- Tidak takut salah.
- Berani bertanya.
- Menghargai ide.
- Selalu bertanya "Mengapa?"
- Membantu teman.
- Menghargai proses.

---

# Peran Guru

Guru adalah perancang pengalaman belajar, bukan sekadar penyampai materi.

# Peran Siswa

Siswa adalah pembangun pengetahuan melalui pengalaman, eksplorasi, diskusi, kesalahan, dan refleksi.

---

# Prinsip AI

AI adalah partner berpikir, bukan pengganti berpikir.

---
