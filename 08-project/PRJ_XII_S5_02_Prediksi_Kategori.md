# PRJ-XII-S5-02 — Prediksi Kategori Sederhana

**Jenis:** Semester · **Mode:** Individu · **Durasi:** 3–4 pertemuan  
**Capability:** CXII-T2, CXII-B1 · **CP:** AD, BK · **MM:** MM-03, MM-04

## Masalah

Memilih pendekatan: rule-based vs model belajar — sering tanpa justifikasi.

## Learning Transformation

Dari “pokoknya pakai ML” → “bandingkan 2 pendekatan, pilih dengan alasan.”

## Requirement

- [ ] Definisikan masalah kategori (3 kelas maks)
- [ ] Solusi A: rule-based (if/else / skor)
- [ ] Solusi B: model mini ATAU transfer sangat sederhana
- [ ] Tabel banding: kelebihan, kekurangan, kapan gagal
- [ ] Pilih satu untuk “produk demo” + alasan

## Varian Rotasi

| Varian | Masalah |
|--------|---------|
| A | Klasifikasi jenis pengumuman (urgent / biasa / arsip) |
| B | Estimasi “siap presentasi?” dari checklist |
| C | Filter konten aman (rule) vs model (diskusi etika) |

## Definition of Done

- [ ] Dua pendekatan diimplementasi cukup untuk dibandingkan
- [ ] Keputusan tertulis + demo kejujuran batasan
