# PRJ-XI-S4-01 — Dashboard Cuaca / Berita (API)

**Jenis:** Semester · **Mode:** Individu / pasangan · **Durasi:** 4 pertemuan  
**Capability:** CXI-T2, CXI-B2 · **CP:** AD, AP, LD · **MM:** MM-17  
**EXP terkait:** EXP_08

## Masalah

Data dari luar (cuaca/berita) tidak “langsung ada” — perlu fetch, tunggu, olah, tampilkan, dan tangani gagal.

## Learning Transformation

Dari “data selalu siap” → “async: loading / sukses / error.”

## Requirement

- [ ] Fetch 1 API publik (cuaca ATAU berita ATAU setara)
- [ ] UI: loading state + error message manusiawi
- [ ] Olah JSON: tampilkan 3–5 field relevan (bukan dump mentah)
- [ ] Dokumentasi singkat: endpoint, field yang dipakai

## Varian Rotasi

| Varian | Kasus |
|--------|--------|
| A | Cuaca kota sekolah |
| B | Headline berita teknologi (filter aman) |
| C | Quote / API edukatif lain yang disetujui guru |

## Definition of Done

- [ ] Demo: matikan jaringan → error tertangani
- [ ] Data diolah, bukan di-paste mentah
- [ ] Reasoning: mengapa field X dipilih

## AI Policy

AI boleh bantu baca docs API — siswa wajib uji sendiri & jelaskan response.
