# PRJ-XI-S4-03 — Inventaris Perpustakaan Mini

**Jenis:** Semester · **Mode:** Individu / pasangan · **Durasi:** 4 pertemuan  
**Capability:** CXI-B2, CXI-T4 · **CP:** AD, AP · **MM:** MM-08, MM-10  
**EXP terkait:** EXP_07

## Masalah

Buku/pinjaman tanpa nomor & relasi — data kacau.

## Learning Transformation

Dari “satu daftar campur” → “entitas + identitas + relasi sederhana.”

## Requirement

- [ ] Skema: Buku (id, judul) · Peminjaman (idBuku, peminjam, tanggal) — boleh di localStorage
- [ ] CRUD buku singkat
- [ ] Catat peminjaman & pengembalian
- [ ] Cari by **id**, bukan judul saja
- [ ] Justifikasi skema tertulis (1/2 halaman)

## Varian Rotasi

| Varian | Kasus |
|--------|--------|
| A | Perpustakaan kelas |
| B | Bank soal / file digital dengan ID |
| C | Inventaris alat lab + peminjaman |

## Definition of Done

- [ ] Skema + app + pencarian by id
- [ ] Kasus dua judul mirip tidak ambigu
