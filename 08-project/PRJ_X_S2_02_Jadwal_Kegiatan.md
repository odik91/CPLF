# PRJ-X-S2-02 — Jadwal Kegiatan Kelas

**Jenis:** Semester · **Mode:** Individu / pasangan · **Durasi:** 3–4 pertemuan  
**Capability:** CX-T1–T3, CX-K2 · **CP:** AP, LD · **MM:** MM-07, MM-09

## Masalah

Jadwal piket / kegiatan OSIS tercecer di chat — sulit dilihat sekilas.

## Learning Transformation

Dari “daftar chat” → “data terstruktur ditampilkan di halaman + bisa diubah.”

## Requirement

- [ ] Tampilkan daftar kegiatan (hari, nama, penanggung jawab)
- [ ] Tambah minimal 1 item lewat UI
- [ ] Highlight kegiatan “hari ini” (kondisi)
- [ ] Peer review: terima 1 saran layout/UX, revisi

## Varian Rotasi

| Varian | Kasus |
|--------|--------|
| A | Jadwal piket kelas |
| B | Jadwal ekstrakurikuler |
| C | Jadwal setoran / kegiatan keagamaan kelas |

## Definition of Done

- [ ] CRUD minimal: Create + Read (+ optional Update)
- [ ] Bukti peer review + revisi
- [ ] Demo 2 menit
