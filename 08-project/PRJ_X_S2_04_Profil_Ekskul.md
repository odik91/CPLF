# PRJ-X-S2-04 — Profil Ekstrakurikuler

**Jenis:** Semester · **Mode:** Individu · **Durasi:** 3 pertemuan  
**Capability:** CX-T1, CX-K1 · **CP:** LD, AP · **MM:** MM-23  
**EXP terkait:** EXP_02 (requirement)

## Masalah

Ekskul ingin dikenal siswa baru — butuh halaman profil yang **informatif**, bukan “asal bagus”.

## Learning Transformation

Dari “desain bebas” → “konten mengikuti requirement yang bisa diuji.”

## Requirement

- [ ] Spesifikasi tertulis 5–7 poin sebelum coding (nama, jadwal, pembina, cara daftar, kontak)
- [ ] Halaman HTML/CSS memenuhi spesifikasi
- [ ] Teman uji: centang acceptance criteria
- [ ] Presentasi: mengapa struktur halaman demikian

## Varian Rotasi

| Varian | Kasus |
|--------|--------|
| A | Profil 1 ekskul pilihan siswa |
| B | Profil panitia kegiatan MA |
| C | Profil “pojok baca” / komunitas kelas |

## Definition of Done

- [ ] Spec + halaman + uji teman lengkap
- [ ] Minimal 1 revisi setelah uji
