# PRJ-XI-S4-02 — Absensi + Persistensi + Git

**Jenis:** Semester · **Mode:** Pasangan / tim kecil · **Durasi:** 4–5 pertemuan  
**Capability:** CXI-T4, CXI-T5, CXI-K2 · **CP:** AP, LD · **MM:** MM-09, MM-20

## Masalah

Absensi hilang saat refresh — dan kerja berdua saling timpa file.

## Learning Transformation

Dari “state di memori saja” → “persist + kolaborasi dengan kontrol versi.”

## Requirement

- [ ] localStorage (atau JSON download/upload) untuk simpan absensi
- [ ] Refresh: data masih ada
- [ ] Repo Git: minimal 2 kontributor, commit berarti
- [ ] README singkat: cara jalankan + pembagian tugas
- [ ] Retrospektif 5 kalimat: apa yang bentrok, bagaimana diselesaikan

## Varian Rotasi

| Varian | Basis |
|--------|--------|
| A | Lanjutkan absensi S3 |
| B | Checklist panitia event + simpan |
| C | Log peminjaman barang + simpan |

## Definition of Done

- [ ] Persistensi terbukti
- [ ] Git history menunjukkan kolaborasi nyata
- [ ] Tidak ada “satu orang mengerjakan semua” tanpa catatan peran
