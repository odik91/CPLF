# PRJ-XII-S6-03 — Klasifikasi Sampah / Tanaman (Citra)

**Jenis:** Nilai · **Mode:** Tim · **Durasi:** 6–8 pertemuan  
**Capability:** CXII-T4, CXII-C1, CXII-K1 · **CP:** AD, LD · **MM:** MM-21, MM-24

## Masalah

Pemilahan sampah / pengenalan tanaman di lingkungan sekolah sering salah — butuh alat bantu edukatif.

## Learning Transformation

Dari “upload foto → jawaban magis” → “transfer learning kritis + edukasi pengguna saat model ragu.”

## Requirement

- [ ] Transfer learning / Teachable Machine / MobileNet path
- [ ] Minimal 2–3 kelas (organik/anorganik/B3 ATAU jenis tanaman lokal)
- [ ] UI: unggah/kamera → label + saran tindakan sederhana
- [ ] Jika confidence rendah → pesan “jangan yakin; cek manual”
- [ ] Esai etika 1 halaman: salah klasifikasi → dampak apa?

## Varian Rotasi

| Varian | Kasus |
|--------|--------|
| A | Sampah kantin sekolah |
| B | Tanaman di halaman MA |
| C | Sortir kertas bekas vs plastik (edukasi) |

## Definition of Done

- [ ] Produk + kebijakan “ragu = tanya manusia”
- [ ] Dataset/sumber dilabel jujur (berapa sampel, bias apa)
