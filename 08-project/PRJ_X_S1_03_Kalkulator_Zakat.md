# PRJ-X-S1-03 — Kalkulator Logika (Zakat)

**Jenis:** Semester · **Mode:** Individu · **Durasi:** 3 pertemuan  
**Capability:** CX-B3, CX-T2, CX-T3 · **CP:** AP · **MM:** MM-13, MM-03  
**EXP terkait:** EXP_04 (kondisi)

## Masalah

Menghitung zakat harta / fitrah secara kasar sering salah karena **kondisi** (nisab, jenis) tidak dicek.

> Catatan: gunakan angka skenario sekolah (disederhanakan). Bukan fatwa — diskusikan dengan guru Fiqih jika perlu. Fokus CPLF = **logika keputusan**.

## Learning Transformation

Dari “langsung hitung” → “cek kondisi dulu, baru hitung; bandingkan dua pendekatan.”

## Requirement

- [ ] Input: jenis (fitrah / mal sederhana) + nominal
- [ ] Minimal 2 cabang kondisi
- [ ] Output: jumlah + alasan singkat (“karena …”)
- [ ] Bandingkan 2 rumus/skenario — pilih satu dengan alasan

## Varian Rotasi

| Varian | Kasus |
|--------|--------|
| A | Zakat fitrah (skenario harga beras) |
| B | Infak sederhana (persentase opsional) |
| C | Biaya kegiatan kelas (iuran vs kas) |

## Media

JS di console atau form sangat sederhana.

## Definition of Done

- [ ] Kondisi + perhitungan benar untuk 3 kasus uji
- [ ] Alasan pilihan solusi tertulis
- [ ] Diskusi etika: angka hanyalah model, bukan ganti konsultasi

## Anti-Pattern

Mengklaim aplikasi sebagai “fatwa digital” tanpa klarifikasi batasan.
