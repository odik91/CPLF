# PRJ-XI-S3-03 — Katalog Kegiatan OSIS

**Jenis:** Semester · **Mode:** Individu · **Durasi:** 3–4 pertemuan  
**Capability:** CXI-T1, CXI-K1 · **CP:** AP, LD · **MM:** MM-07, MM-23

## Masalah

Kegiatan OSIS diumumkan sporadis — butuh katalog filterable (mis. minggu ini / selesai).

## Learning Transformation

Dari “halaman statis” → “daftar dinamis + filter kondisi.”

## Requirement

- [ ] Spec tertulis (siapa pengguna: siswa / panitia)
- [ ] Tampil daftar kegiatan dari array/object
- [ ] Filter minimal 1 dimensi (status / kategori)
- [ ] Form tambah kegiatan
- [ ] Uji acceptance dengan teman non-coder jika bisa
