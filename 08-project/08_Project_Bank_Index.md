# Project Bank CPLF

**Version:** 0.1 (Draft — living; dikaji ulang setelah praktik ajar)  
**Status:** Sengaja **tidak Frozen permanen** (bersama 07 & 09). Freeze sementara untuk cohort boleh; revisi diharapkan dari evidensi kelas.  
**Peran:** Katalog project sebagai **bukti capability** — bukan daftar latihan sintaks.

## Aturan Emas

> Project adalah evidence of learning.  
> Yang dinilai: masalah → reasoning → artefak → iterasi → transfer — bukan “berapa baris kode”.

Setiap project wajib punya:
1. **Masalah nyata** (konteks MA / kehidupan siswa)
2. **Capability target** (kode CX / CXI / CXII)
3. **Definition of Done** yang bisa diuji
4. **Wajib reasoning** (demo 1–3 menit: mengapa solusi seperti ini)

## Rotasi Antar Kelas (anti-kebocoran)

Seperti Experience Library: **trap/capability sama**, **kasus berbeda**.

```text
PRJ_{Kelas}_{Semester}_{Kode}     → brief induk
PRJ_{Kelas}_{Semester}_{Kode}_A   → varian rotasi (opsional di brief)
```

Guru paralel: kelas X-1 ambil varian A, X-2 ambil B, dst. Catat di jurnal: `Kelas | PRJ | Varian | Tanggal`.

## Bukti yang Harus Dikumpulkan

| Aspek | Bentuk bukti |
|-------|----------------|
| Observation | Screenshot / demo gejala & perbaikan |
| Reasoning | Slide 1 halaman atau lisan 1–3 menit |
| Communication | Presentasi / peer review |
| Iteration | Sebelum–sesudah (minimal 1 revisi) |
| Transfer | 2–3 kalimat: pola ini dipakai di mana lagi? |
| Technical | Artefak berjalan (link / folder) |

## Anti-Pattern Project

- Project = “ikut tutorial YouTube tanpa masalah sendiri”
- Menilai hanya UI cantik / akurasi model tinggi
- Tim: satu orang coding, lainnya numpang nama
- Capstone XII tanpa bagian etika & batasan model
- Menyalin project kelas lain (pakai rotasi varian)

---

## Cara Memakai

1. Pilih **1 project semester** dari katalog (atau setara yang disetujui guru).
2. Isi brief dengan [00_Project_Brief_Template.md](./00_Project_Brief_Template.md) jika custom.
3. Hubungkan ke **Experience** terkait (opsional) dari folder `07`.
4. Demo + refleksi di unit project silabus (X1.8, X2.7, dst.).
