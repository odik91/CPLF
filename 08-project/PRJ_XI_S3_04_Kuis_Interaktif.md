# PRJ-XI-S3-04 — Kuis Interaktif

**Jenis:** Semester · **Mode:** Individu · **Durasi:** 3–4 pertemuan  
**Capability:** CXI-T1, CXI-B1 · **CP:** AP · **MM:** MM-12, MM-13

## Masalah

Latihan soal di chat sulit dilacak skor; butuh kuis singkat di browser.

## Learning Transformation

Dari “soal di dokumen” → “alur: tampil soal → jawab → skor → selesai.”

## Requirement

- [ ] Minimal 5 soal (pilihan ganda)
- [ ] Navigasi soal / satu per layar
- [ ] Hitung skor di akhir
- [ ] Feedback benar/salah (boleh di akhir atau per soal)
- [ ] State: indeks soal, jawaban user

## Varian Rotasi

| Varian | Kasus |
|--------|--------|
| A | Kuis istilah Multimedia / web |
| B | Kuis literasi digital (aman password, hoaks) |
| C | Kuis ringan mapel lain (kolaborasi guru mapel) |

## Definition of Done

- [ ] Alur selesai tanpa stuck
- [ ] Skor sesuai kunci
- [ ] Jelaskan model state
