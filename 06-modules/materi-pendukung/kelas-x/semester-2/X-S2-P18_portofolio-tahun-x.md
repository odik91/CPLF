## 1. Pengetahuan yang Dikuasai Guru

- **Learning transformation:** dari problem solver (S1) → web sederhana (S2) — **identitas cara belajar**, bukan "sudah jadi developer".
- **Opening frame:** "Bukan identitas profesi — identitas cara belajar" — hindari oversell karier.
- **Portofolio minimum tahun X:**
  - Project S1 (link/screenshot)
  - Project S2 (link/screenshot)
  - Refleksi 1 halaman: apa yang berubah dalam cara berpikir?
  - 1 contoh klarifikasi AI/medsos yang pernah dilakukan
- **Progress Card CX:** self-assessment + validasi guru — 3 capability + bukti dari semester.
- **Reflect:** 3 Mental Model yang paling terasa (mis. spec dulu, error=info, iterasi peer).
- **Optional showcase gallery** — kelas/orang tua — rayakan growth, bukan ranking.
- **Transfer Kelas XI:** preview dari halaman → **sistem** (DOM dalam, async, data, tim).
- **Arsip CPLF:** Progress Card + narasi masuk arsip siswa — sumatif formatif.

## 4. Materi Inti

### Opening (0–10 menit)

Frame identitas belajar:

- Tahun X = fondasi berpikir komputasional + ekspresi web sederhana
- Portofolio = bukti **perjalanan**, bukan sertifikat ahli
- Teaser XI: sistem lebih dalam — fondasi hari ini yang dipakai

### Susun portofolio (10–30 menit)

**Struktur kurasi** (guru guide, siswa isi):

| Bagian | Isi | Tips kurasi |
|--------|-----|-------------|
| Cover/narasi | Nama, kelas, tahun ajaran | 2–3 kalimat tujuan belajar |
| Artefak S1 | Screenshot/link PRJ S1 | + 1 kalimat masalah & solusi |
| Artefak S2 | Screenshot/link PRJ S2 | + bukti revisi peer (before/after) |
| Refleksi | 1 halaman | Perubahan cara berpikir — bukan daftar fitur |
| Literasi | 1 contoh klarifikasi AI/medsos | Protokol klarifikasi — jujur |

**Format fleksibel:** Google Doc, Notion sederhana, HTML statis 1 halaman, folder PDF — yang penting **siswa kurasi sendiri**.

Guru keliling — clarifying questions:

- "Artefak mana yang paling tunjukkan iterasi?"
- "Kalimat refleksi — spesifik atau generic?"

### Progress Card CX (30–50 menit)

Isi [09_Progress_Card](../../../09-rubrik/09_Progress_Card.md):

- 3 capability CX yang tumbuh (OBS, REA, ITR, COM, TEC, TRF — pilih 3)
- Bukti dari semester (project, debug sheet, peer review)
- Self level + guru validasi — **bukan** debat nilai di depan kelas

### Reflect — 3 Mental Model (50–70 menit)

Diskusi oraal + tulis individual — contoh model CPLF:

| Mental Model | Bukti tahun X |
|--------------|---------------|
| Masalah sebelum solusi | Spec P15 S1 / wireframe P12 S2 |
| Error = informasi | Debug clinic P13, OBS showcase |
| Iterasi melalui peer | P15–P16 revisi dokumentasi |
| Validasi melindungi user | PRJ S2 form & pesan error |
| Mengapa > cantik | Presentasi P17 reasoning |

Siswa pilih **3 yang paling terasa** — dengan contoh konkret milik mereka.

### Optional gallery / orang tua (70–85 menit)

- Walk-through station — applause proses
- Orang tua: lihat portofolio anak, **bukan** ranking
- Guru 2 menit synthesis — pola kuat tahun X + teaser XI

### Closing (85–90 menit)

- Kumpul Progress Card + portofolio (link/folder)
- Feedback untuk revisi modul living draft (07–09) — opsional sticky note guru
- Closing tahun X — apresiasi effort

## 5. Alur Live Coding / Live Modeling

### Persiapan

- Template Progress Card kosong (rubrik resmi).
- Checklist portofolio minimum di papan.
- Izin foto/publikasi — formulir sekolah jika perlu.
- **Tidak** sesi coding — fokus kurasi & refleksi.
- Contoh **struktur** portofolio di papan (outline saja, bukan isi siswa).

### Skrip facilitator

```text
[0–10] Opening — identitas belajar, bukan identitas profesi
[10–30] Kurasi portofolio — S1 + S2 + narasi + literasi
        Guru model OUTLINE di papan, siswa isi konten sendiri
[30–50] Progress Card CX — self + validasi guru (individual/quiet)
[50–70] Reflect 3 Mental Model — diskusi + tulis
[70–85] Optional gallery / orang tua — no ranking
[85–90] Closing + kumpul arsip + teaser Kelas XI
```

### Modeling outline portofolio (papan — generic)

```text
1. Siapa saya belajar (2 kalimat)
2. Project S1 — masalah → solusi → 1 pelajaran
3. Project S2 — masalah → solusi → bukti iterasi peer
4. Refleksi: sebelum CPLF vs sekarang — 1 halaman
5. Contoh klarifikasi AI/medsos — 1 episode jujur
6. Target belajar Kelas XI — 1 kalimat
```

**Dilarang:** guru mengetik isi refleksi siswa di proyektor.

## 6. Latihan Membaca Kode

Portofolio **bukan** membaca kode baru. Gunakan **cuplikan artefak siswa** (anonim/izin) untuk latihan **kurasi & refleksi** — proyeksi 5 menit:

```text
// Cuplikan commit message siswa A (anonim)
"fix: pesan error validasi nominal — saran peer P15"
```

| Pertanyaan membaca (kurasi) | Kunci |
|-----------------------------|-------|
| Mengapa masuk portofolio? | Bukti ITR + peer review — proses |
| Narasi refleksi dari ini? | "Saya belajar feedback spesifik lebih berguna dari 'bagus'" |

```javascript
// Before/after 3 baris — pilih untuk portofolio
// before: alert("error");
// after: errEl.textContent = "Nominal wajib diisi";
```

| Pertanyaan membaca | Kunci |
|--------------------|-------|
| Capability CX mana? | COM (pesan ke user), TEC (DOM), ITR (revisi) |
| Masuk bagian portofolio? | S2 artefak + caption 1 kalimat mengapa |

## 7. Praktik Mandiri Siswa

1. **Portofolio minimum** — S1 + S2 + refleksi + literasi.
2. **Progress Card CX** — 3 capability + bukti.
3. **Reflect 3 Mental Model** — tulis dengan contoh konkret.
4. **Kurasi sendiri** — pilih screenshot/link yang represent proses.
5. **Target Kelas XI** — 1 kalimat.
6. **Kumpul arsip** — ke guru sesuai prosedur sekolah.

## 8. Kesalahan Umum

| Siswa | Guru |
|-------|------|
| Portofolio = dump screenshot tanpa narasi | Coach: 1 kalimat konteks per artefak |
| Refleksi generic ("jadi lebih pintar") | Tanya: contoh spesifik P13/P15/P17 |
| Malu project "jelek" | Normalisasi — pilih bukti iterasi, bukan polish |
| Copy refleksi teman | Individual — authentic voice |
| Guru ranking di gallery | Explicit: tidak ada juara |
| Oversell ke orang tua | Frame fondasi + cara belajar |
