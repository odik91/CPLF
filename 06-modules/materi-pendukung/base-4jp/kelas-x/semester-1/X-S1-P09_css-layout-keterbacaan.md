## 1. Pengetahuan

- Keterbacaan ≠ warna cantik. Seringnya masalah: **sesak**, **baris terlalu lebar**, **judul tidak beda**.  
- `margin` ≈ jarak luar · `padding` ≈ jarak dalam (ulang intuisi P08, perdalam lewat pengalaman).  
- `max-width` + `margin: 0 auto` = trik klasik kolom terbaca.  
- Flex hari ini: **satu wadah**, anak sejajar (nav). Bukan kuliah `justify-content` lengkap — cukup `display: flex`, `gap`, `flex-wrap`.  
- Grid / framework / absolute “rapi paksa” = di luar scope.
