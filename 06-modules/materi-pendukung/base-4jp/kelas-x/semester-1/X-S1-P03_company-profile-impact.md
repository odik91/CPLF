## 1. Pengetahuan yang dikuasai guru

### Tujuan pedagogis (bukan teknis)

- Memberi **impact emosional-kognitif**: “saya bisa dapat halaman utuh… tapi tidak tahu mana yang benar.”
- Deadlock = bahan bakar rasa penasaran → P04 requirement, P05 klarifikasi.
- **Bukan** mengajar vibe coding, **bukan** sesi debug.

### Hubungan P02

- Prompt = **input** (sama seperti keyword Google).
- Output bisa beda meski prompt sama (model, sampling, konteks tersembunyi) — cukup disebut “mesin tidak menjamin hasil identik”; jangan kuliah LLM.

### Tag HTML yang dilabel hari ini

Cukup nama + fungsi kasar: `html`, `head`, `body`, `h1`, `p` (+ opsional `a`, `ul`, `li`).  
Jangan jelaskan atribut/CSS kecuali siswa bertanya — parkir.

### AI Policy

Formal di **P05**. Hari ini: hasil = bukti proses; jangan paste ke WA sebagai “tugas selesai.”

## 2. Recall spiral

| Tanya | Inti |
|-------|------|
| P02: output = ? | f(input) |
| P02: hasil #1 = fakta? | Belum — verifikasi |
| Hari ini prompt sama — hasil beda. Analoginya? | Input/konteks/mesin; tanpa paham sulit nilai “benar” |

---

## 3. Etika penyampaian hari ini

| Aturan | Penerapan |
|--------|-----------|
| No debug workshop | Tolak permintaan “benerin dulu” dengan parkir ke pertanyaan |
| Prompt seragam | Satu teks kelas — jangan biarkan siswa “percantik prompt” sebelum gallery |
| Live modeling | Generate **1×** saja di depan; sisanya siswa |
| Penilaian | OBS + REA + pertanyaan penasaran — bukan cantik HTML |
| Fallback | 3–4 HTML sample berbeda jika AI/lab down |

---

## 4. Skrip sesi (ringkas)

```text
[1] Compass di papan: Bandingkan, jangan patch
[2] Recall P02 1 siswa
[3] Guru generate 1× + buka HTML (jangan kuliah tag)
[4] Siswa generate prompt seragam — simpan file
[5] Gallery 2–3 hasil — sticky: sama/beda?
[6] Trap: "Mana yang benar?" — diam produktif 2–3 menit
[7] Clarify: yang hilang = paham & requirement
[8] Scaffold: tunjuk 5 tag pada 1 file
[9] Practice: lembar kenali tag + 3 pertanyaan (ANTI perbaiki)
[10] Exit + preview P04
```

## 5. Respons siap pakai

| Siswa bilang | Respons guru |
|--------------|--------------|
| “Pak, HTML-nya error” | “Parkir. Tulis sebagai pertanyaan #n — nanti kita belajar bacanya.” |
| “Punya aku lebih bagus” | “Bagus ≠ benar. Apa bedanya dengan punya teman? Catat.” |
| “Boleh ganti prompt?” | “Setelah gallery. Hari ini kita uji input yang sama.” |
| “Jadi AI jelek ya?” | “AI kuat generate. Kita yang belum punya cara **minta & menilai**.” |

## 6. Kesalahan umum

| Siswa | Guru |
|-------|------|

| Malu karena “tidak paham” | Membiarkan malu — reframing: pertanyaan = kemajuan |
