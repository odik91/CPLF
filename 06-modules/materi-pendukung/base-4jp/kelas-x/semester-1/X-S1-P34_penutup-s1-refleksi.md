## Pengetahuan

- P34 = jurnal + arsip + transfer. Bukan P33 jilid 2, bukan S2 P01.
- Preview S2 4JP: **halaman hidup / DOM** (HTML/CSS dasar sudah di S1). Jendela, bukan bab.
- Folder skill **bukan** project baru.
- Arsip termasuk jejak “jelek” (log, gap). Menghapus jejak = menghapus bukti tumbuh.
- Jurnal lemah = “saya belajar banyak.” Jurnal kuat = kemampuan + file + perilaku.

## Kunci jurnal (setelah kelas tebak mana yang lemah)

**Lemah:** “S1 seru. Saya lebih jago coding. S2 saya mau React.”
**Kuat:** “C3: saya bisa uji AC tanpa membuka `script.js` dulu (bukti: lembar P28). Kesalahan: hapus AC di kepala P32. Perbaikan: kartu status. Target S2: list di halaman, karena di S1 daftar menu masih HTML statis.”

## Recall

P33 panggung. P34 milik tertulis. S2 belum dibangun.

## Etika

Tidak ranking. Tidak memaksa “semua L”. Tidak izinkan hapus gap demi rapor.

## Checklist exit

- [ ] Jurnal terisi bukti
- [ ] Arsip jujur
- [ ] Satu target S2
- [ ] Tanpa coding fitur
- [ ] Preview S2 ≤ 15 menit konsep (bukan live DOM lesson)

## KBC

**Kejujuran pada diri sendiri.** Jurnal tanpa bukti adalah klaim. Arsip yang utuh adalah tanggung jawab pada “saya di S2.”
