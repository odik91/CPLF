## 1. Pengetahuan

- Satu halaman panjang tanpa peta = pembaca tersesat (meski CSS bagus).  
- Loncat static: `id="…"` + `<a href="#…">` — cocok huruf per huruf.  
- `id` harus unik di satu dokumen.  
- Nav palsu (`button` / `div` berkursor tanpa tautan) = trap klasik.  
- Multi-*file* HTML boleh disebut sebagai “nanti / project” — bukan target hari ini.
