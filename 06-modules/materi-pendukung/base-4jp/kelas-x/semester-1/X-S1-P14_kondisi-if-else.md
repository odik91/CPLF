## 1. Pengetahuan

- Kondisi = satpam: cek aturan → boleh / tidak.  
- Di halaman: kedua cabang harus **terlihat** (ubah `#pesan`).  
- `===` untuk banding string; `>=` untuk angka.  
- Trap klasik: `=` (isi nilai) vs `===` (banding).  
- Nested / multi-syarat = P15.
