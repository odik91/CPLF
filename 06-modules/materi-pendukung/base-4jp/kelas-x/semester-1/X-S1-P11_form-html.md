## 1. Pengetahuan

- Form = wadah data, bukan ornamen.  
- `name` = identitas field (jembatan P02: input harus jelas).  
- `label for` + `id` = aksesibilitas & kejernihan.  
- Placeholder ≠ pengganti label.  
- Static S1: `action="#"` + catatan jujur lebih baik daripada klaim “terkirim.”  
- Backend / JS validasi penuh = parkir (P13+ / project).
