## Pengetahuan

- Syntax: program tak dapat diparse; Reference: nama tidak ada; logic: program jalan tetapi hasil keliru.  
- Ubah satu hal untuk satu hipotesis.  
- Pesan konsol dan baris adalah bukti, bukan penghukuman.  
- Jangan menambah konsep baru atau DOM hari ini.

## Checklist exit

- [ ] Bug direproduksi
