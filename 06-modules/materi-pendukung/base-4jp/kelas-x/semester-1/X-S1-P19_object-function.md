## Pengetahuan

- Array = nilai berurutan; object = properti bernama.  
- Function didefinisikan dahulu, lalu dipanggil.  
- Parameter adalah nama input; argumen adalah nilai saat panggilan.  
- `return` mengirim hasil; `console.log` hanya menampilkan.  
- Tahan nested object, object sebagai parameter, method, callback, DOM.

## Recall

P18 mengolah banyak nilai sejenis. P19 menyusun satu data dengan peran berbeda dan membungkus proses berulang.

## Etika

Nama properti dan function harus menunjukkan maksud; hindari `data`, `x`, atau function bernama kabur.
