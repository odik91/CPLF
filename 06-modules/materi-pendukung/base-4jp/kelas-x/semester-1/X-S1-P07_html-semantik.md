## 1. Pengetahuan

- Semantik = **peran**, bukan dekorasi.  
- Browser sering menampilkan “sup `div`” mirip kerangka bermakna → trap “sama saja.”  
- Manfaat yang relevan MA: keterbacaan kode, akses dasar, selaras spek, siap CSS di P08 tanpa berantakan.  
- Satu `h1` per halaman (aturan kelas hari ini — sederhanakan).

### Cuplikan trap (siapkan 2 file)

**Buruk:** lima `div` bertingkat, judul pakai `p` tebal atau loncat heading.  
**Baik:** `header`/`main`/`section`/`footer` + `h1`/`h2` selaras spek.
