## Pengetahuan

- Array = daftar berindeks dari 0.  
- `length` = banyak elemen; indeks terakhir = `length - 1`.  
- `for (let i = 0; i < arr.length; i = i + 1)` adalah pola hari ini.  
- Object, `while`, `forEach`, `map` ditunda.  
- `typeof []` → `"object"`: sebut sebagai jebakan, bukan materi object.

## Recall

P13–P17: nilai skalar, variabel, Boolean, keputusan. P18: banyak nilai sejenis + pengulangan.

## Etika

Jangan menyembunyikan error indeks di balik “nanti diperbaiki AI.” Trace indeks salah adalah kesempatan belajar, bukan malu.
