## Pengetahuan

- P33 = panggung. Coding ditutup. Live-fix dilarang.
- Kartu status P32 = naskah gap. Kartu presentasi = 4 slot.
- Folder skill **bukan** project baru — hanya lembar.
- Audiens yang hanya bilang “bagus” = gagal C4.
- P34 terpisah: jangan menyusup jurnal semester di menit 170.

## Kunci demo guru (setelah kelas tebak “mana yang buruk”)

**Showcase buruk (jangan ditiru):**
1. “Ini project kantin, keren kan?” — tidak ada masalah/pengguna.
2. Klik semua tombol sambil diam, lalu “itu JS-nya.”
3. “Yang gap itu nanti saya perbaiki sekarang.” — buka editor.
4. Bandingkan dengan teman: “punya dia lebih ramai.”

**Showcase baik:**
1. Masalah: siswa cek status menu di istirahat, tanpa tanya banyak orang.
2. Mengapa: satu halaman + 2 klik; bukan form ke kantin (bukan S1).
3. Demo: klik `#tombolUtama` → teks `#pesan` sesuai AC.
4. Gap: “title sempat salah di P32, sudah ditambal; nav tidak kutambah karena tidak ada di spek.”

## Recall

P32 garis DoD. P33 jelaskan. P34 tulis tumbuh apa.

## Etika

Tidak ranking. Tidak mempermalukan gap. Tidak izinkan live CSS “biar rapi di depan kamera.”
