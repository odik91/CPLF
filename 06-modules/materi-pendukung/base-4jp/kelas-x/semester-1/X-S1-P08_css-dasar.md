## 1. Pengetahuan

- HTML = struktur · CSS = presentasi.  
- Demonstrasi kuat: **satu HTML**, dua file CSS → tampilan beda total.  
- Selector hari ini: elemen (`body`, `h1`, `p`, `section`, `header`, `footer`) — class boleh singkat jika perlu, bukan fokus.  
- Spacing: `margin` (luar) vs `padding` (dalam) — cukup intuisi, bukan kuliah box model penuh.  
- Kontras: hindari abu muda di putih / kuning di putih.
