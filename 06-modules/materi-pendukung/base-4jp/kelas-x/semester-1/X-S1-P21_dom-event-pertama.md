## Pengetahuan

- DOM bukan HTML source persis, tetapi representasi halaman saat ini.  
- `id` harus unik; `getElementById` memakai nama tanpa `#`.  
- Script akhir body mencegah elemen belum tersedia.  
- Listener menunggu event, bukan menjalankan aksi saat halaman termuat.  
- Tahan form, validasi, `querySelector`, class toggling, framework.

## Checklist exit

- [ ] Satu elemen + satu tombol  
- [ ] `id` tepat  
- [ ] Listener click  
- [ ] Bukti konsol  
- [ ] Uji sebelum/setelah  
- [ ] Tanpa form/selector kompleks
