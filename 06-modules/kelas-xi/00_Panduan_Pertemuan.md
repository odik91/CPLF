## Blok Waktu Default (90 menit)

| Menit | Fase CPLF | Aktivitas guru |
|-------|-----------|----------------|
| 0–5 | Opening | Do Now / recall spiral dari X |
| 5–20 | **Experience** | Skenario sistem, IPO, kolaborasi |
| 20–30 | **Trap + Observe + Question** | Challenge “tinggal tambah tombol” |
| 30–40 | **Clarify** | Prinsip Bernalar; desain sebelum kode |
| 40–50 | **Reason → Concept** | Konsep + diagram/skema |
| 50–75 | **Practice** | Build / refactor / Git / API |
| 75–85 | **Reflect + Transfer** | Jurnal; pola ke project |
| 85–90 | Exit | Exit ticket; preview |

## Adaptasi Cepat

| Situasi | Ambil dari | Tambah ke |
|---------|------------|-----------|
| API down / offline | Fetch live | Mock JSON lokal |
| Git belum setup | Branch exercise | Pair pada 1 repo guru |
| Tim tidak seimbang | Solo + peer review wajib | Rotasi role minggu depan |
| Diskusi desain panjang | Practice | PR: blueprint selesai |

## Checklist Guru

- [ ] Spiral X diingatkan 1 kalimat (bukan ulang teori penuh)  
- [ ] Blueprint/skema sebelum coding panjang (S3+)  
- [ ] AI coding: wajib jelaskan kode yang dipakai (MM-00, MM-22)  
- [ ] Git S4: atribusi & amanah data teman  
- [ ] 2 aspek rubrik formatif terpilih  

---

## Anti-Pattern Kelas XI

- Project = tutorial copy-paste tanpa IPO  
- Satu orang hero coding di tim S4  
- Async tanpa loading/error state  
- Review hanya “bagus/jelek” tanpa kriteria
