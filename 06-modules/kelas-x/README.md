# Modul Pertemuan — Kelas X

**Version:** 0.1 (Draft living)  
**Mapel:** Multimedia (pemrograman web) · MA · Fase E  
**Struktur:** `semester-1/` · `semester-2/` · 18 pertemuan per semester

## Konvensi penamaan

```text
X-S{semester}-P{nomor}_{slug-topik}.md

Contoh: X-S1-P04_robot-mie-algoritma.md
```

| Kode | Arti |
|------|------|
| X | Kelas X |
| S1 / S2 | Semester 1 / 2 |
| P01–P18 | Pertemuan ke-1 … 18 |

## Alokasi waktu (referensi resmi)

| Asumsi | Nilai | Sumber |
|--------|-------|--------|
| 1 JP (jam pelajaran) | **45 menit** | Kurikulum Merdeka SMA/MA — kelas X & XI: 36 minggu/tahun |
| 1 pertemuan | **2 JP** | **90 menit** (kombinasi 2×45 menit berturut atau 2 slot) |

> Jika sekolah memakai 1 JP saja per minggu: **potong timeline menjadi ~45 menit** — prioritaskan Experience + Clarify + Practice singkat; Reflect/Transfer jadi PR 1 halaman.

## Isi setiap modul pertemuan

Setiap file memuat **timeline menit-per-menit** agar guru tidak blank:

1. Opening & hook  
2. Experience + Cognitive Trap  
3. Clarify (Prinsip Bernalar)  
4. Concept  
5. Practice / coding  
6. Reflect & Transfer  
7. Exit ticket + catatan guru
