# Panduan Pertemuan CPLF (Kelas X)

**Version:** 0.1 (Draft)

## Referensi JP

| Item | Durasi |
|------|--------|
| 1 JP | 45 menit |
| Pertemuan standar CPLF-X | **2 JP = 90 menit** |
| Pertemuan ringkas (1 JP) | 45 menit — lihat kolom “Adaptasi 1 JP” di tiap modul |

Asumsi tahun ajaran MA kelas X: **±36 minggu** intrakurikuler (Kurikulum Merdeka).

---

## Blok Waktu Default (90 menit)

Gunakan sebagai **acuan**, bukan hukum rigor. ±5 menit fleksibel.

| Menit | Fase CPLF | Aktivitas guru |
|-------|-----------|----------------|
| 0–5 | Opening | Do Now / hook / recall pertemuan lalu |
| 5–20 | **Experience** | Skenario, role-play, ROBI, props |
| 20–30 | **Trap + Observe + Question** | Diskusi; jangan sebut konsep dulu |
| 30–40 | **Clarify** | Prinsip Bernalar; uji asumsi |
| 40–50 | **Reason → Concept** | Nama konsep; papan/slide minimal |
| 50–75 | **Practice** | Latihan / coding / worksheet |
| 75–85 | **Reflect + Transfer** | Jurnal 2–3 kalimat; “dipakai di mana lagi?” |
| 85–90 | Exit | Exit ticket; preview minggu depan |

### Pertemuan project (P15–P17 S1, P12–P16 S2)

| Menit | Fokus |
|-------|--------|
| 0–10 | Checkpoint tim/individu; clarifying question |
| 10–70 | Build / debug / peer help terstruktur |
| 70–85 | Demo singkat atau stand-up 1 menit/siswa |
| 85–90 | Catat blocker untuk minggu depan |

### Pertemuan showcase (P18 S1, P17–P18 S2)

| Menit | Fokus |
|-------|--------|
| 0–60 | Presentasi 3–5 menit + tanya jawab |
| 60–80 | Peer feedback (rubrik ringkas) |
| 80–90 | Refleksi capability |

---

## Adaptasi Cepat

| Situasi | Ambil waktu dari | Tambah ke |
|---------|------------------|-----------|
| Diskusi trap panjang | Practice | Jadikan PR; practice singkat di kelas |
| Lab/laptop lambat | Concept lecture | Practice di minggu berikutnya (spiral) |
| Kelas 1 JP saja | Practice + Reflect | Potong 50%; Experience+Clarify wajib tetap |
| Siswa “kapan coding?” | Concept | Practice ≥20 menit hari itu |

---

## Checklist Guru (sebelum kelas)

- [ ] Transformasi berpikir 1 kalimat sudah dibaca  
- [ ] Experience + trap siap (varian rotasi jika perlu)  
- [ ] Laptop/props/alternatif offline  
- [ ] 2–3 guiding questions tertulis  
- [ ] Exit ticket / formatif rubrik (2 aspek)  
- [ ] AI policy hari itu (boleh/tidak + klarifikasi)

---

## Exit Ticket (contoh generik)

1. Satu asumsi yang kubongkar hari ini: …  
2. Satu konsep + bahasa sendiri: …  
3. Satu hal masih bingung: …

---

## Anti-Pattern

- Mengisi 90 menit dengan slide definisi  
- Trap mempermalukan siswa  
- Tanpa practice coding >3 pertemuan berturut (Kelas X)  
- Menghabiskan waktu karena ide guru melebar — parkir ke backlog
