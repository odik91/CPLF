## Blok Waktu Default (90 menit)

| Menit | Fase CPLF | Aktivitas guru |
|-------|-----------|----------------|
| 0–5 | Opening | Recall spiral · hook etika/nilai |
| 5–20 | **Experience** | Skenario AI nyata MA |
| 20–30 | **Trap + Question** | “ChatGPT = AI”, “model selalu benar” |
| 30–40 | **Clarify** | Peta konsep · batasan model |
| 40–50 | **Concept** | Data / tensor / TF.js / CV |
| 50–75 | **Practice** | Eksperimen · train mini · integrasi web |
| 75–85 | **Reflect + Transfer** | Jurnal batasan · manfaat umat |
| 85–90 | Exit | Exit ticket |
