## 2. Ringkasan konsep

- **Transformasi hari ini:** dari kumpulan file/repo → **portofolio capability** siap XII + Progress Card updated.
- **Portofolio minimum (modul):**
  - Project S3 + S4 (link/repo)
  - 1 blueprint / ER
  - 1 refleksi kolaborasi Git
  - Progress card updated
- **Timeline:** opening contoh portofolio → concept Progress Card → practice susun → gallery walk → reflect → closing preview XII.
- **Progress Card:** status capability (Belum / Berkembang / Terlihat / Kokoh) + bukti PRJ/EXP — bukan daftar nilai bab.
- **Fokus Kelas XI template:** CXI-B1, B2, T1–T5, K1, K2, C1.
- **Gallery walk:** 1 feedback sticky peer — spesifik, bukan ranking.
- **Reflect:** 3 capability CXI terkuat · 1 target XII.
- **Arsip:** opsional rapor / orang tua / showcase lintas kelas — modul catatan guru.
- **Preview XII:** data lebih dalam · ML ringan · etika AI.

---

## 3. Materi praktik

### Opening — contoh portofolio (0–10 menit)

Guru tunjuk **struktur section** (bukan copas isi):

```text
1. Identitas + tahun ajaran
2. Project S3 — masalah · IPO · link · 1 iterasi peer
3. Project S4 — masalah · data/API · tim · Git · link
4. Blueprint / ER (1 artefak)
5. Refleksi kolaborasi Git (5–10 kalimat jujur)
6. Progress Card — capability + bukti
7. Target XII
```

**Tanpa** demo project baru — kurasi artefak existing.

### Concept — Progress Card (10–30 menit)

Jelaskan [09_Progress_Card](../../../09-rubrik/09_Progress_Card.md):

| Status | Arti untuk guru |
|--------|-----------------|
| Belum | Tidak ada bukti cukup |
| Berkembang | Bukti formatif; belum konsisten |
| Terlihat | Project/demo konsisten |
| Kokoh | Terlihat + transfer / bantu teman |

**Mapping bukti S3/S4 → capability (contoh guru):**

| Capability | Bukti S3 | Bukti S4 |
|------------|----------|----------|
| CXI-T2 | Logika state/handlers | Transform pipeline API |
| CXI-T4 | Debug render/event | Debug fetch/offline/merge |
| CXI-K2 | Peer review P16 S3 | Peer review + Git P16 S4 |
| CXI-K1 | Demo reasoning S3 | Presentasi tim P17 |
| COM | Spec + demo jujur | Atribusi README + retro |

Guru **tidak** isi kartu untuk siswa — facilitate + spot-check.

### Practice — susun portofolio (30–60 menit)

Media fleksibel: Notion · GitHub Pages · Google Site · kertas binder.

**Checklist siswa:**

- [ ] Link repo S3 + S4 (public atau link sekolah)
- [ ] Screenshot/demo GIF opsional — bukan wajib cantik
- [ ] 1 blueprint atau ER (docs/spec, diagram)
- [ ] Refleksi kolaborasi Git (conflict, atribusi, amanah data)
- [ ] Progress Card updated — min 5 capability dengan bukti
- [ ] Redact secrets & data pribadi

Guru keliling — clarifying questions only.

### Gallery walk (60–75 menit)

Rotasi station / walk kelas:

- **+1 sticky kuat** per portofolio yang dilihat — spesifik
- Contoh: "Refleksi Git conflict merge — konkret & jujur."
- **Bukan:** "Portofolio kamu paling bagus."

### Reflect (75–85 menit)

Individual:

```text
3 capability CXI terkuat tahun ini — bukti dari PRJ/EXP:
1. …
2. …
3. …

1 target XII (spesifik):
```

### Closing — preview XII (85–90 menit)

- Data lebih dalam · ML ringan · etika AI
- Simpan portofolio — arsip MA opsional
- Apresiasi growth year XI — bukan ranking
