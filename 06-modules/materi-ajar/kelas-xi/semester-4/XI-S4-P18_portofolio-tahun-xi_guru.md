## 1. Pengetahuan yang Dikuasai Guru

- **Transformasi hari ini:** dari kumpulan file/repo → **portofolio capability** siap XII + Progress Card updated.
- **Portofolio minimum (modul):**
  - Project S3 + S4 (link/repo)
  - 1 blueprint / ER
  - 1 refleksi kolaborasi Git
  - Progress card updated
- **Timeline:** opening contoh portofolio → concept Progress Card → practice susun → gallery walk → reflect → closing preview XII.
- **Progress Card:** status capability (Belum / Berkembang / Terlihat / Kokoh) + bukti PRJ/EXP — bukan daftar nilai bab.
- **Fokus Kelas XI template:** CXI-B1, B2, T1–T5, K1, K2, C1.
- **Gallery walk:** 1 feedback sticky peer — spesifik, bukan ranking.
- **Reflect:** 3 capability CXI terkuat · 1 target XII.
- **Arsip:** opsional rapor / orang tua / showcase lintas kelas — modul catatan guru.
- **Preview XII:** data lebih dalam · ML ringan · etika AI.

## 3. Etika Penyampaian Pertemuan Ini

| Aturan | Penerapan spesifik hari ini |
|--------|----------------------------|
| **Facilitator kurasi** | Guru bantu struktur portofolio — **bukan** menulis narasi/refleksi siswa. |
| **Jangan takeover keyboard** | Siswa susun Notion/GitHub Pages/kertas sendiri. |
| **Jangan bagikan portofolio contoh penuh** | Tidak template copas narasi guru — model **struktur section** saja. |
| **Clarifying questions** | "Bukti capability mana dari PRJ S4?", "Refleksi Git — contoh konkret?" |
| Gallery walk | Peer +1 kuat spesifik — bukan ranking portofolio |
| Amanah | Portofolio **tidak** include data pribadi teman, API key, screenshot WA |
| Kejujuran atribusi | Refleksi kolaborasi jujur — bukan klaim hero coding |

### Larangan portofolio

| Jangan | Mengapa |
|--------|---------|
| Guru tulis refleksi siswa | Authentic voice — COM |
| Siswa copas narasi AI tanpa bukti | Minta link commit/screenshot spesifik |
| Portofolio = screenshot UI saja | Capability = reasoning + iterasi + kolaborasi |
| Ranking "portofolio terbagus" | Gallery = feedback sticky, bukan juara |
| Include secret keys / data pribadi | Amanah data — redact before publish |

### Script coaching portofolio

```text
"Section project — link repo + 3 kalimat masalah & DoD."
"Blueprint/ER — pilih S3 atau S4 — 1 artefak cukup."
"Refleksi Git — conflict? atribusi? Start/Stop/Continue dari P17."
"Progress Card — status + bukti link, bukan klaim kosong."
"Target XII — 1 capability fokus, spesifik."
```

---

## 4. Materi Inti

### Opening — contoh portofolio (0–10 menit)

Guru tunjuk **struktur section** (bukan copas isi):

```text
1. Identitas + tahun ajaran
2. Project S3 — masalah · IPO · link · 1 iterasi peer
3. Project S4 — masalah · data/API · tim · Git · link
4. Blueprint / ER (1 artefak)
5. Refleksi kolaborasi Git (5–10 kalimat jujur)
6. Progress Card — capability + bukti
7. Target XII
```

**Tanpa** demo project baru — kurasi artefak existing.

### Concept — Progress Card (10–30 menit)

Jelaskan [09_Progress_Card](../../../09-rubrik/09_Progress_Card.md):

| Status | Arti untuk guru |
|--------|-----------------|
| Belum | Tidak ada bukti cukup |
| Berkembang | Bukti formatif; belum konsisten |
| Terlihat | Project/demo konsisten |
| Kokoh | Terlihat + transfer / bantu teman |

**Mapping bukti S3/S4 → capability (contoh guru):**

| Capability | Bukti S3 | Bukti S4 |
|------------|----------|----------|
| CXI-T2 | Logika state/handlers | Transform pipeline API |
| CXI-T4 | Debug render/event | Debug fetch/offline/merge |
| CXI-K2 | Peer review P16 S3 | Peer review + Git P16 S4 |
| CXI-K1 | Demo reasoning S3 | Presentasi tim P17 |
| COM | Spec + demo jujur | Atribusi README + retro |

Guru **tidak** isi kartu untuk siswa — facilitate + spot-check.

### Practice — susun portofolio (30–60 menit)

Media fleksibel: Notion · GitHub Pages · Google Site · kertas binder.

**Checklist siswa:**

- [ ] Link repo S3 + S4 (public atau link sekolah)
- [ ] Screenshot/demo GIF opsional — bukan wajib cantik
- [ ] 1 blueprint atau ER (docs/spec, diagram)
- [ ] Refleksi kolaborasi Git (conflict, atribusi, amanah data)
- [ ] Progress Card updated — min 5 capability dengan bukti
- [ ] Redact secrets & data pribadi

Guru keliling — clarifying questions only.

### Gallery walk (60–75 menit)

Rotasi station / walk kelas:

- **+1 sticky kuat** per portofolio yang dilihat — spesifik
- Contoh: "Refleksi Git conflict merge — konkret & jujur."
- **Bukan:** "Portofolio kamu paling bagus."

### Reflect (75–85 menit)

Individual:

```text
3 capability CXI terkuat tahun ini — bukti dari PRJ/EXP:
1. …
2. …
3. …

1 target XII (spesifik):
```

### Closing — preview XII (85–90 menit)

- Data lebih dalam · ML ringan · etika AI
- Simpan portofolio — arsip MA opsional
- Apresiasi growth year XI — bukan ranking

## 5. Alur Live Coding / Live Modeling

### Persiapan

- Template **struktur** portofolio di papan (bukan isi penuh).
- Link [09_Progress_Card](../../../09-rubrik/09_Progress_Card.md) — siswa lihat format.
- Sticky notes gallery walk.
- Daftar artefak S3 dari P18 S3 / showcase — siswa bawa link.
- **Tidak** sesi coding project baru.

### Skrip facilitator

```text
[0–10] Opening — struktur portofolio + contoh section (bukan copas)
[10–30] Progress Card concept — status + bukti S3/S4
[30–60] Practice — siswa susun portofolio
        Guru keliling: clarifying questions
[60–75] Gallery walk — +1 sticky spesifik
[75–85] Reflect — 3 capability + 1 target XII
[85–90] Closing + arsip opsional + preview XII
```

### Modeling sticky gallery (papan)

```text
Portofolio siswa X (anonim di pleno):

+1 KUAT: "Section S4 menjelaskan keputusan field API + link commit transform."
(BUKAN: "Copy template portofolio ini.")
```

### Redaction check (guru float)

```text
[ ] Tidak ada API key di screenshot
[ ] Tidak ada nomor HP/data absensi asli
[ ] README atribusi match refleksi (tidak klaim solo)
```

---

## 6. Latihan Membaca Kode

Portofolio **bukan** latihan kode baru. Latihan **membaca bukti capability** — cuplikan artefak proyeksi:

### README excerpt

```markdown
## Contributors
- A: UI, render, loading states
- B: fetch + transform pipeline
- C: localStorage + QA checklist

## Run
Live Server → index.html
Offline test: DevTools → Network offline
```

| Pertanyaan membaca | Kunci |
|--------------------|-------|
| Bukti CXI-K1/COM? | Atribusi + cara run reproducible |
| Progress Card map? | K2 peer · T4 debug offline · COM atribusi |

### Commit message sample

```text
feat: add loading skeleton for fetch
fix: peer review — error message when offline
docs: update README attribution after merge
```

| Pertanyaan membaca | Kunci |
|--------------------|-------|
| Bukti ITR? | Iterasi peer review visible in history |
| Narasi portofolio? | Siswa tulis before/after P16 — link commit |

### ER sketch (PRJ-03)

```text
BUKU (id, judul) —< PEMINJAMAN (id, idBuku, peminjam, tanggal)
```

| Pertanyaan membaca | Kunci |
|--------------------|-------|
| Artefak blueprint? | Cukup untuk section portofolio |
| Transfer XII? | Model relasi — fondasi data |

---

## 7. Praktik Mandiri Siswa

1. **Susun portofolio** — S3 + S4 + blueprint/ER + refleksi Git.
2. **Update Progress Card** — status + bukti link per capability.
3. **Gallery walk** — beri +1 sticky spesifik ke ≥2 teman.
4. **Reflect** — 3 capability terkuat + 1 target XII.
5. **Redact** secrets & data pribadi sebelum share.
6. **Submit link/kertas** — sesuai kebijakan sekolah.

---

## 8. Kesalahan Umum

| Siswa | Guru |
|-------|------|
| Portofolio = galeri screenshot UI | Coaching: reasoning + link + iterasi |
| Refleksi generic ("jadi lebih pintar") | Tanya: contoh P14/P16/P17 |
| Klaim capability tanpa bukti | Wajibkan link PRJ/EXP |
| Copas narasi AI portofolio | Minta commit/screenshot spesifik siswa |
| Include API key / data teman | Wajib redact — amanah |
| Guru tulis Progress Card siswa | Siswa isi — guru spot-check |
| Ranking portofolio terbagus | Explicit: gallery bukan kompetisi |
| Skip project S3 | Minimum modul — kumpul dari arsip S3 |
