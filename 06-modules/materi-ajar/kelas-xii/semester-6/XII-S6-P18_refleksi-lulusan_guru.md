## Pengetahuan Guru

P18 = **penutup identitas** — bukan ujian. Kumpulkan portofolio untuk arsip MA.

### Filosofi penutup

> Dari lulus mapel → **pembelajar seumur hidup** dengan identitas **problem solver** — teknologi & AI sebagai alat amanah, bukan identitas utama.

**Guru ucapkan terima kasih** — 3 tahun proses > 1 angka rapor.

### Refleksi wajib (1–2 halaman siswa)

1. Siapa saya sebagai pembelajar masalah?
2. 3 mental model CPLF yang masih dipakai (OBS, REA, COM, ITR, TRF, TEC — pilih 3)
3. 1 keputusan etika AI yang dibanggakan
4. Rencana belajar setelah lulus (**bukan harus IT**)

### Letter to future self (1 tahun)

- Format: surat untuk diri sendiri — dibuka ~1 tahun setelah lulus
- Guru kumpulkan (amplop/sealed digital) — **opsional** kirim email scheduled
- Isi: 1 harapan · 1 kekhawatiran jujur · 1 prinsip CPLF

### Journey map X → XI → XII

| Tahun | Prompt refleksi |
|-------|-----------------|
| X | Experience yang mengubah cara lihat "teknologi" |
| XI | Experience kolaborasi paling challenging |
| XII | Experience etika/AI yang paling membekas |

**Experience > nilai** — guru model dengan contoh anonim 30 detik.

### Prinsip Bernalar — bawa ke mana?

Tidak perlu jadi programmer. Contoh transfer:

- OBS → observasi di kuliah/kerja
- REA → tidak percaya claim tanpa bukti
- COM → terima feedback without personal attack
- E3/E4 → AI sebagai partner, bukan oracle

---

## Recall Spiral

Opening **Do Now 5 menit** — tulis diam.

> "1 masalah dunia yang **belum** bisa kamu selesaikan — **OK**."

Normalisasi: lulus CPLF ≠ tahu semua. **Pembelajar seumur hidup** = berani belajar terus.

| Pertanyaan pleno (opsional) | Kunci |
|------------------------------|-------|
| P17 showcase — 1 feedback sticky yang membekas? | Spesifik |
| P16 portofolio — growth area jujur? | OK untuk "belum" |
| 3 tahun — 1 capability paling kokoh? | Bukti project |

## Materi Inti

### Transformasi belajar

**Dari:** Lulus mapel → **pembelajar seumur hidup** dengan identitas problem solver.

### Timeline fasilitator (90 menit)

| Menit | Fase | Peran guru |
|-------|------|------------|
| 0–10 | Opening | Do Now — masalah belum selesai OK |
| 10–25 | Experience | Letter to future self |
| 25–40 | Reflect | Journey map X→XI→XII |
| 40–55 | Clarify | Prinsip Bernalar setelah MA |
| 55–70 | Practice | Refleksi final 1–2 halaman + Progress Card |
| 70–85 | Sharing | Sukarela 5 siswa × 1 menit |
| 85–90 | Closing | Moto · doa · terima kasih · arsip portofolio |

### Template refleksi final (papan — siswa expand)

```markdown
# Refleksi Lulusan CPLF — [Nama]

## 1. Pembelajar masalah
(Siapa saya — bukan daftar software)

## 2. Tiga mental model CPLF
- …
- …
- …

## 3. Keputusan etika AI
(1 momen capstone — E1/E2/E3/E4)

## 4. Setelah lulus
(Belajar apa · bukan harus IT)

## 5. Terima kasih / penutup
(Opsional — 2 kalimat)
```

### Sharing sukarela — protokol aman

- Max 1 menit — timer
- **Tidak** wajib — alternatif: submit tulisan saja
- Larangan: roast · banding IQ · tekan karir IT
- Guru moderasi — cut jika terlalu personal untuk publik

## Latihan Membaca Dokumen — Refleksi

### Snippet A — Refleksi generic

```text
Saya jadi coder handal. AI is the future. Saya siap kerja di Google.
```

| Pertanyaan membaca | Kunci jawaban |
|--------------------|--------------|
| TRF cukup? | **Tidak** — overclaim · identitas sempit |
| Perbaikan? | Problem solver + mental model spesifik + etika |
| Identitas CPLF? | Capability & amanah — bukan employer name-drop |

### Snippet B — Refleksi jujur (model)

```text
Saya belum paham semua ML — tapi saya bias cek klaim dengan REA.
Keputusan etika: menolak fitur wajah tanpa consent walaupun "keren".
Setelah lulus: kuliah pendidikan — tech untuk media pembelajaran.
```

| Pertanyaan membaca | Kunci jawaban |
|--------------------|--------------|
| Level refleksi? | **Kuat** — TRF + etika + rencana non-IT OK |
| Progress Card? | CXII-C2 etika · REA · TRF evidence |
| Guru response? | Validasi — bukan push karir IT |

## Identitas Lulusan — Refleksi Guru (facilitator notes)

Gunakan framing ini saat moderasi:

| Framing salah | Framing CPLF |
|---------------|--------------|
| "Kalian harus lanjut IT" | "Kalian bisa **beralasan** dengan teknologi di bidang apapun" |
| "Yang tidak jago coding gagal" | "Capability COM/REA/Etika sama pentingnya dengan TEC" |
| "AI akan ganti pekerjaan" | "AI butuh pengguna **beretika** — itu peran kalian" |
| Nilai rapor = identitas | **Progress Card + portofolio** = bukti proses |

### 3 mental model — contoh bank (jika siswa blank)

| Model | Contoh kalimat siswa |
|-------|---------------------|
| OBS | "Wawancara pengguna dulu sebelum coding" |
| REA | "Tidak percaya akurasi tanpa N data" |
| COM | "Feedback P12 = hadiah, bukan serangan" |
| ITR | "Revisi dari reviewer before present" |
| TRF | "Pola fallback non-AI dari P05 masih dipakai" |
| TEC + Etika | "Demo gagal = bukti amanah" |

## Praktik Mandiri

Siswa — penutup:

1. Selesaikan refleksi 1–2 halaman (5 poin struktur).
2. Letter to future self — seal & serahkan.
3. Progress Card final — self + guru validasi nanti.
4. Submit portofolio ke arsip MA.
5. (Opsional) 1 kalimat untuk murojaah — share sukarela.

Guru — setelah kelas:

1. Arsip portofolio + Progress Card per siswa.
2. Catatan narasi capability untuk konferensi wali murid (opsional).
3. **Tidak** assign homework baru — penutup bersih.
