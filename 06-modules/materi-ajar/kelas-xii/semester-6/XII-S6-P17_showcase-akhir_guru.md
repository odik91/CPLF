## Pengetahuan Guru

Showcase = **komunitas MA** dengan accountability — bukan pameran ranking UI.

| Format | Kapan | Catatan |
|--------|-------|---------|
| Booth (stasi) | Ruang luas, banyak pengunjung | QR + poster etika + demo gagal |
| Demo berurutan | Kelas tunggal | Timer ketat — etika tetap wajib |
| Hybrid | Capstone booth + S5 ringkas | Prioritas capstone XII |

### Etika showcase — aturan layar

- **Tidak** tampilkan data pribadi siswa/wajah tanpa consent di monitor publik
- Hormati pengguna capstone — jangan ejek prediksi salah di depan tamu
- Demo gagal **boleh** ditunjukkan ke pengunjung — itu bukti amanah (E1)
- Foto arsip: blur wajah jika perlu · koordinasi kepala sekolah

### Booth checklist (wajib per tim)

- [ ] QR ke repo/demo live
- [ ] 1 poster etika & batasan (E1–E4 ringkas)
- [ ] Demo gagal siap ditunjukkan
- [ ] Semua anggota tim hadir — rotasi jelaskan
- [ ] Portofolio P16 accessible (QR kedua atau same page)

### Penghargaan capability — bukan juara UI

| Hindari | Ganti dengan |
|---------|--------------|
| "UI terkeren" | "Kejujuran batasan & demo gagal" (E1) |
| "Akurasi tertinggi" | "Wawancara pengguna tercatat" (OBS) |
| "Hanya 1 tim menang" | 3–5 kategori capability — banyak siswa diakui |

Contoh kategori: Kolaborasi (COM) · Iterasi dari feedback (ITR) · Etika proaktif (E1–E4) · Transfer narasi 3 tahun (TRF).

### Synthesis slide — pola 3 tahun CPLF

Guru siapkan **1 slide** (80–90 menit):

```text
Kelas X  → masalah & requirement (Bernalar)
Kelas XI → app tim & persist (Kolaborasi)
Kelas XII → model + etika + capstone (Amanah teknologi)
= Lulusan MA: problem solver beretika
```

## Materi Inti

### Transformasi belajar

**Dari:** Presentasi kelas → **showcase** komunitas MA dengan accountability ke pengguna nyata.

### Timeline fasilitator (90 menit)

| Menit | Fase | Peran guru |
|-------|------|------------|
| 0–5 | Opening | Etika showcase · format booth/demo |
| 5–50 | Showcase | Booth rotasi atau demo berurutan |
| 50–65 | Visitors | Piket · OSIS · kelas X–XI — sticky feedback |
| 65–80 | Synthesis | 1 slide pola 3 tahun CPLF |
| 80–90 | Apresiasi | Penghargaan capability · foto arsip |

### Sticky feedback pengunjung (template papan)

```text
Untuk tim ______:
+ Saya suka bukti ______ (spesifik)
? Saya tanya tentang ______ (etika/dampak)
```

### Rotasi booth (jika format stasi)

- Pengunjung: 8–10 menit/stasi — 3 menit demo + gagal + poster etika
- Tim: 1 speaker utama + 1 demo operator — rotasi
- Guru: keliling — flag overclaim ke tamu

---

## Alur Facilitator

### Persiapan (H-1 jika mungkin)

- [ ] Koordinasi kepala sekolah · ruang · pengunjung
- [ ] Meja/stasi · QR printed · poster etika
- [ ] Brief OSIS/piket/kelas X–XI: protokol sticky
- [ ] Kamera arsip — consent foto grup
- [ ] Backup offline demo (video demo gagal)
- [ ] Synthesis slide 3 tahun CPLF
- [ ] Sertifikat/penghargaan capability (kertas cukup)

### Skrip fasilitator

```text
[LANGKAH 1 — Opening 0–5 menit]
Ucapkan: "Showcase = hormat pengguna & amanah — bukan adu gengsi."
Tampilkan: aturan layar — no data pribadi · demo gagal OK
Brief pengunjung: tanya etika & manfaat

[LANGKAH 2 — Showcase 5–50 menit]
Buka booth / mulai demo berurutan
Timer per tim jika sequential
Keliling: pastikan poster etika & demo gagal tampil

[LANGKAH 3 — Visitors 50–65 menit]
Undang kelas X–XI · OSIS · guru lain
Sticky feedback — spesifik
Scope: pengunjung isi format 2 baris

[LANGKAH 4 — Synthesis 65–80 menit]
1 slide: X → XI → XII CPLF
Pleno 5 menit: "Apa pola 3 tahun?"
Scope: identitas lulusan problem solver

[LANGKAH 5 — Apresiasi 80–90 menit]
Umumkan 3–5 kategori capability — bukan 1 juara
Ucapkan: "P18 refleksi lulusan — penutup 3 tahun."
Foto arsip — blur jika perlu
```

```

Poster: (kosong)
```

| Pertanyaan membaca | Kunci jawaban |
|--------------------|--------------|

## Praktik Mandiri

Tim — sebelum showcase:

1. Test QR dari HP pengunjung (bukan hanya laptop tim).
2. Poster etika: E1 batasan + E2 data (jika relevan) — 1 layar A4.
3. Assign rotasi: siapa demo · siapa jelaskan etika · siapa notes feedback.
4. Re-run demo gagal — reproducible di stres pengunjung.
5. Kumpulkan sticky — 1 revisi opsional untuk P18 refleksi.

Pengunjung (kelas X–XI):

1. Isi 2 sticky per tim visited — spesifik + pertanyaan etika.
2. 1 kalimat: "Apa yang ingin kamu pelajari dari XII?"

---

## Kesalahan Umum

| Siswa | Guru |
|-------|------|
| Hanya demo sukses ke tamu | Ingatkan: gagal = differensiator E1 |
| Overclaim ke pengunjung | Intervensi lembut — minta baca batasan |
| Booth tanpa anggota lengkap | Gate: minimal 2/3 tim present |
| Data wajah di layar publik | Stop demo — privacy E2 |
| Showcase jadi ranking | Reframe penghargaan multi-kategori |
| Pengunjung hanya puji UI | Brief: tanya dampak salah prediksi |
