## Pengetahuan Guru

P16 = **narasi perjalanan** X → XI → XII — bukan dump link GitHub.

| Portofolio minimum | Bukti yang diharapkan |
|--------------------|------------------------|
| Kelas X: web/JS | 1 project + 1 kalimat masalah |
| Kelas XI: app + kolaborasi/Git | README peran / commit graph |
| Kelas XII: capstone + etika | Demo link + paragraf batasan |
| Progress Card updated | Status capability jujur — bukan semua "Kokoh" |
| 1 halaman refleksi 3 tahun | Identitas **problem solver** |

### Identitas lulusan — framing guru

> **Bukan:** "Saya jago coding / AI"  
> **Adalah:** "Saya pemecah masalah yang bisa **beralasan**, **berkolaborasi**, dan **beretika** dengan teknologi."

Capability > stack. Etika capstone = bukti CXII-C1/C2.

### Progress Card — spiral 3 tahun

| Tahun | Fokus kartu | Evidence tipikal |
|-------|-------------|------------------|
| X | CX-B1–B4, CX-T1–T4, CX-K1 | PRJ poster/web, EXP flowchart |
| XI | CXI-B1, B2, T1–T5, K1, C1 | PRJ tim, Git, async |
| XII | CXII-B1, B2, T1–T4, K1, C1, C2 + E1–E4 | Capstone S6, rubrik etika |

**Anti-pattern kartu:** Semua status "Kokoh" — guru validasi dengan bukti.

### Template portofolio (sesuaikan fasilitas sekolah)

| Platform | Kapan pakai |
|----------|-------------|
| Kertas + QR | Lab terbatas / ujian praktik |
| GitHub Pages | Repo sudah ada dari XI |
| Notion / Google Sites | Siswa familiar docs |
| PDF export | Arsip wali murid |

Guru siapkan **1 template** — jangan 5 format berbeda tanpa panduan.

## Materi Inti

### Transformasi belajar

**Dari:** Kumpulan file/link → **narasi** perjalanan X → XI → XII dengan identitas jelas.

### Struktur 1 halaman refleksi 3 tahun (papan)

```text
1. Siapa saya sebagai pemecah masalah? (bukan daftar bahasa pemrograman)
2. 3 momen CPLF yang mengubah cara berpikir (X, XI, XII — masing-masing 1)
3. 3 capability terkuat + bukti link
4. 1 growth area jujur + rencana belajar setelah lulus
5. 1 keputusan etika AI yang dibanggakan (capstone)
```

### Kurasi project — 2 terbaik/tahun + capstone

| Tahun | Kriteria "terbaik" | Bukan |
|-------|-------------------|-------|
| X | Masalah jelas + AC/flowchart | Hanya warna cantik |
| XI | Kolaborasi + fitur jalan | Solo tanpa refleksi |
| XII | Capstone + etika | Demo tanpa batasan |

### Gallery walk — sticky feedback

Protokol 2 menit/stasi:

- 1 sticky **spesifik:** "Bukti capability X di project Y"
- 1 sticky **tanya:** "Narasi refleksi — apa growth area-nya?"
- Larangan: "Keren" saja

## Alur Facilitator

### Persiapan

- [ ] Template portofolio (1 format) — link di LMS/papan
- [ ] Progress Card blank atau digital — [09_Progress_Card](../../../../09-rubrik/09_Progress_Card.md)
- [ ] Sticky notes / padlet untuk gallery walk

### Skrip fasilitator (90 menit — selaras modul)

```text
[LANGKAH 1 — Opening 0–10 menit]
Tampilkan: contoh portofolio 1 project — artefak + capability + refleksi
Ucapkan: "Portofolio = cerita masalah, bukan museum screenshot."
Tanya: "Coder vs problem solver — beda presentasi ke wali murid?"

[LANGKAH 2 — Concept 10–25 menit]
Jelaskan Progress Card X–XI–XII — status jujur
Ucapkan: "Kokoh butuh bukti — Berkembang juga OK."
Scope: [09_Progress_Card] — guru punya salinan

[LANGKAH 3 — Kurasi 25–45 menit]
Siswa pilih 2 project/tahun + capstone — link + 1 kalimat masalah
Keliling: TTS "Capability mana bukti paling kuat?"

[LANGKAH 4 — Capability 45–60 menit]
Tulis 3 capability terkuat + 1 growth area
Update Progress Card XII — siswa self-assess, guru validasi nanti

[LANGKAH 5 — Gallery walk 60–75 menit]
Rotasi stasi — sticky 2+1
Ucapkan: "Feedback spesifik — bukan ranking."

[LANGKAH 6 — Identitas 75–85 menit]
Pleno pendek: "Problem solver, bukan tukang coding"
Refleksi 1 halaman — draft minimal 3 paragraf

[LANGKAH 7 — Exit 85–90 menit]
Submit URL/kertas draft + Progress Card draft
Ucapkan: "P17 showcase — portofolio jadi booth."
```

## Latihan Membaca Dokumen

### Snippet A — Entri portofolio lemah

```markdown
## Project XI
Link: github.com/...
Bagus.
```

| Pertanyaan membaca | Kunci jawaban |
|--------------------|--------------|
| Gap? | Tidak ada masalah, capability, refleksi |
| Perbaikan? | "Masalah: absensi manual → capability: CXI-T3 async" |
| TRF? | Jelaskan pola yang dipakai di XII |

### Snippet B — Progress Card overclaim

```text
Semua capability: Kokoh
```

| Pertanyaan membaca | Kunci jawaban |
|--------------------|--------------|
| Valid? | **Tidak** — anti-pattern [Progress Card] |
| Guru? | Minta 1 bukti per Kokoh — turunkan jika tidak ada |
| COM? | Kejujuran self-assess = capability |

---

## Praktik Mandiri

1. Kumpulkan link 2 project/tahun + capstone — verifikasi jalan.
2. Tulis 1 kalimat masalah + 1 capability per entri.
3. Update Progress Card XII — minimal 5 baris capability + bukti.
4. Draft refleksi 1 halaman (5 poin struktur di atas).
5. Gallery walk — terima 2 sticky, revisi 1 entri portofolio.
6. Final URL/kertas — siap P17 booth.

**Variasi kelas lambat:** kertas + QR — 1 project/tahun cukup jika dokumentasi XI kurang.

**Variasi kelas cepat:** GitHub Pages live + README portofolio bilingual 1 paragraf.
