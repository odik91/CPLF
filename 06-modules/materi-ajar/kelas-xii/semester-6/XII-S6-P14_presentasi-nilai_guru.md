## Pengetahuan Guru

P14 = capstone **dinilai** — bukan lomba UI terkeren. Nilai MA: **amanah · tidak overclaim · argumen teknologi**.

| Komponen presentasi | Wajib | Bobot penilaian |
|---------------------|-------|-----------------|
| Pengguna & wawancara singkat | Masalah nyata MA | OBS, REA |
| Justifikasi teknologi | Transfer vs rule vs QR — **kenapa** | REA, TEC |
| Demo sukses | 1 alur pengguna | TEC |
| **Demo gagal** | **Wajib** — input spesifik | **Etika E1 ≥ 2** |
| Dokumen etika lisan | E1–E4 ringkas | E1–E4 |
| Transfer ke masa depan | Pola reusable | TRF |
| Revisi dari P12/P13 | Sebut 1 perubahan konkret | ITR |

### Gate kelulusan project (XII capstone)

| Syarat | Minimum |
|--------|---------|
| DoD artefak PRJ | Model/fitur jalan + web + dokumen etika |
| E1 batasan & kejujuran | Level ≥ 2 |
| E1 = 1 (overclaim/sembunyikan gagal) | **Dikembalikan** — meski demo mulus |
| E2 (jika kamera/data pribadi) | Level ≥ 2; **≥ 3 disarankan** |
| Kasus gagal | Ditunjukkan live, bukan di slide saja |

### Format presentasi 5–6 menit + 2 menit Q&A

```text
0:00 — Masalah & pengguna (wawancara 1 kalimat) (45s)
0:45 — Kenapa transfer/rule/QR — bukan "karena keren" (45s)
1:30 — Demo sukses (1m 30s)
3:00 — Demo GAGAL + mitigasi UI (1m) ← wajib
4:00 — Etika: data · consent · batasan (45s)
4:45 — 1 revisi dari peer review (30s)
5:15 — Transfer: pola ke project lain (30s)
5:45 — Q&A panel (2m)
```

### Panel — 2 pertanyaan etika (guru/teman)

Contoh bank pertanyaan (pilih 2 — jangan mempermalukan):

1. "Data apa yang kalian kumpulkan — semua perlu?"
2. "Jika model salah — siapa yang rugi?"
3. "Kenapa QR bukan wajah?" / sebaliknya dengan alasan
4. "Klaim apa yang sengaja **tidak** kalian buat?"
5. "Bagian mana yang AI bantu vs kalian pahami sendiri?" (E3)

**Nilai MA:** pertanyaan menguji **amanah**, bukan jebakan retorika.

### Self-assess + guru catat rubrik

- Siswa: checklist singkat 6 aspek + E1–E4 (honest, tidak angka)
- Guru: lembar skor [Rubrik Project] + [Etika AI] — **jangan baca angka di depan kelas**
- Narasi wajib 2–3 kalimat capability per tim

| Nilai MA presentasi: pamer atau amanah? | **Amanah** — batasan & kejujuran |

## Etika Penyampaian

| Aturan | Penerapan spesifik hari ini |
|--------|----------------------------|
| **No copas** | Penilaian dari **demo live** + argumen sendiri — bukan slide template |
| **Live modeling** | Guru buka 30 detik: "contoh kalimat batasan jujur" — bukan script overclaim |
| **Per baris / scope** | Timer 6 menit — interrupt lembut jika lewat tanpa demo gagal |
| **Recall** | 1 kalimat spiral sebelum tim pertama |
| **Rubrik** | Guru pakai lembar internal — siswa self-assess deskriptor, bukan angka |
| **No ranking akurasi** | "Model paling akurat" **bukan** kriteria — puji kejujuran batasan |
| **Pengguna eksternal** | Jika undang OSIS/wali — brief: tanya dampak & etika, bukan "judge UI" |

## Alur Facilitator / Presentasi

### Persiapan

- [ ] Urutan presentasi + timer visible
- [ ] Lembar rubrik guru per tim (Project + Etika)
- [ ] Bank 5 pertanyaan panel etika
- [ ] (Opsional) Undang 1–2 pengguna eksternal — brief etika
- [ ] Proyektor + backup offline jika demo web gagal
- [ ] Screenshot artefak untuk arsip portofolio P16

### Skrip fasilitator

```text
[LANGKAH 1 — Opening 0–5 menit]
Ucapkan: "Hari ini nilai argumen & amanah — bukan lomba UI."
Tampilkan: urutan tim + format 5 menit + demo gagal wajib
Tanya: "Apa beda demo sukses dengan demo gagal dalam rubrik etika?"
Scope: E1 level 3 = proaktif tunjukkan gagal.

[LANGKAH 2 — Presentasi 5–55 menit]
Timer 6 menit/tim — warning menit 5
Keliling: catat rubrik — OBS/REA/COM/ITR/TRF/TEC + E1–E4
Interrupt lembut jika demo gagal dilewati: "Tunjukkan 1 kasus gagal sekarang."
Panel Q&A: 1 pertanyaan teknologi + 1 etika per tim (jika waktu)

[LANGKAH 3 — Panel 55–70 menit]
Pleno: 2 pertanyaan etika — volunteer tim jawab 1 menit
Ucapkan: "Jawaban jujur 'belum sempurna' > overclaim."
Scope: normalisasi ketidaksempurnaan model.

[LANGKAH 4 — Rubrik 70–85 menit]
Siswa isi self-assess 1 frasa/aspek
Guru finalize lembar skor + narasi capability 2–3 kalimat
Ucapkan: "Narasi untuk Progress Card & portofolio — bukan hanya angka."

[LANGKAH 5 — Closing 85–90 menit]
Preview P16: kurasi X–XI–XII
Ucapkan: "Simpan repo, dokumen etika, screenshot presentasi hari ini."
Scope: exit — 1 kalimat identitas: problem solver, bukan "tukang demo AI".
```

## Latihan Membaca Dokumen / Script

### Snippet A — Script overclaim

```text
"Model kami 99% akurat dan selalu bisa diandalkan pengguna."
(Demo gagal: tidak direncanakan)
```

| Pertanyaan membaca | Kunci jawaban |
|--------------------|--------------|
| Level E1? | **1** — overclaim + sembunyikan gagal |
| Gate kelulusan? | **Dikembalikan** meski UI bagus |
| Perbaikan script? | Sebut N sampel, batasan, demo gagal proaktif |

### Snippet B — Justifikasi teknologi lemah

```text
"Pakai Teachable Machine karena modul suruh."
```

| Pertanyaan membaca | Kunci jawaban |
|--------------------|--------------|
| REA cukup? | **Tidak** — perlu alasan pengguna & constraint |
| Justifikasi baik? | "Pengguna butuh klasifikasi 3 kelas di HP — TM cukup, training from scratch tidak realistis di MA" |
| TRF? | "Pola: fitur AI + fallback manual jika confidence rendah" |

---

## Praktik Mandiri

Setelah presentasi — per tim:

1. Lengkapi self-assess 6 aspek + E1–E4 (1 frasa bukti).
2. Narasi capability 2–3 kalimat untuk guru/Progress Card.
3. Screenshot slide/demo + link repo ke folder portofolio.
4. Refleksi 1 kalimat: "Keputusan etika yang dibanggakan."
5. (Opsional) Tonton rekaman/re-run demo gagal — pastikan reproducible.

**Variasi jam sempit:** 4 menit presentasi + 1 menit Q&A — panel etika dipindah ke P17.

---

## Kesalahan Umum

| Siswa | Guru |
|-------|------|
| Hanya demo sukses | Timer stop — wajib demo gagal sebelum lanjut |
| Etika = slide terakhir copy-paste | Tanya lisan E2 data & E1 batasan |
| Overclaim akurasi | Redirect ke rubrik E1 — catat level 1 |
| Semua bicara sekaligus | Enforce script P13 — rotasi speaker |
| Debat teknologi tanpa pengguna | Tanya: "Siapa yang rugi jika salah?" |
| Malu demo gagal | Normalisasi: "Gagal = bukti level 3 E1" |
| Guru umumkan ranking tim | Narasi individual — hindari malu publik |
