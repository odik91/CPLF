# Latihan P02 — Update DOM Aman

Demo: ubah teks dengan `textContent`, bandingkan singkat dengan `innerHTML`.

## Cara pakai

1. Buka `index.html` di browser.  
2. Catat teks `#status` sebelum klik.  
3. Klik **Ubah status**.  
4. Di area demo: coba kedua tombol dengan string yang sama; isi lembar handout.  
5. Reset demo bila perlu.

## Batas

- Ya: `textContent` · banding `innerHTML` terkendali  
- Tidak: form · validasi · list dinamis · framework · `innerHTML` sebagai kebiasaan  

Klik hanya pemicu (sudah dikenal S1); materi event dalam = P03.
