# Latihan P01 — Recall S1 + DOM Query

**Bukan project baru.** Folder demo untuk prediksi selector + bukti konsol.

## Cara pakai

1. Buka `index.html` di browser.  
2. F12 → Console.  
3. Isi lembar prediksi di handout **sebelum** membaca log.  
4. Bandingkan prediksi vs output.

## Batas

- Ya: `querySelector`, `querySelectorAll`, recall `getElementById`  
- Tidak: ubah `textContent` sebagai fitur (P02) · event baru · form · framework  

Komentar di `script.js` hanya DEFINISI / GUIDE / TRAP.
