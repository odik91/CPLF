## B. Pendukung mengajar

### Persiapan

- Papan: 4 blok S1 (satu baris masing-masing). Jangan ceramah 40 menit ulangan.
- Preview S2: **maks. 10–15 menit** di fase Concept. Rujukan guru: [X-S2_Index 4JP draft](../../../../base-4jp/kelas-x/semester-2/X-S2_Index.md) — jangan bagikan sebagai silabus wajib jika masih draft; cukup arah “halaman hidup.”
- Salin `jurnal-s1.md` dan `checklist-arsip.md` ke folder project siswa.
- USB/cloud opsional untuk cadangan — jangan jadi lomba zip.

### Kunci jurnal (RAHASIA sampai prediksi)

Lihat [materi pendukung](../../../../materi-pendukung/base-4jp/kelas-x/semester-1/X-S1-P34_penutup-s1-refleksi.md).

### Pengetahuan di lidah

- Bukti = nama file atau AC, bukan perasaan.
- S2 4JP **tidak** mengulang HTML dari nol.
- Menghapus gap menghapus bukti P32–P33.
- Target S2 satu celah, bukan React.

### Recall satu kalimat

> "P33 kamu bicara. Hari ini kamu menulis surat untuk dirimu di S2. Jangan merobek lampirannya."

### Miskonsepsi

1. Penutup = hari kosong / film.
2. Portofolio harus tanpa cacat.
3. S2 = ulangi P07–P08.
4. “Belajar banyak” sudah cukup sebagai jurnal.
5. Preview = izin coding DOM sekarang.

### Etika

Tidak ranking. Tidak memaksa tiga kemampuan sama untuk semua. Siswa yang projectnya retak tetap menulis bukti yang ada.

### Skrip live

#### 0–10 · Orientation · Mengingat · C1

> "Pertemuan terakhir S1. Bukan panggung lagi. Bukan bengkel. Bukan S2. Kita menulis apa yang tumbuh dan merapikan surat untuk semester depan."

Papan: **jurnal · arsip · transfer · jendela S2.**

#### 10–30 · Scaffold · Memahami · C2

Empat blok, empat outcome. Siswa tunjuk **satu P** yang paling terasa. Tanpa pidato.

#### 30–50 · Experience · C2–C4

Baca jurnal lemah. Kelas: mana bukti? Lalu jurnal kuat. Bandingkan.

#### 50–65 · Trap · Menganalisis · C4

1. Guru pura-pura hapus `log-revisi.md`. → “Itu bukti perbaikan.”
2. Buka MDN `addEventListener` 5 menit seolah pelajaran. → tutup: “jendela, bukan bab.”
3. “Siapa paling keren P33?” → tolak.
4. “S2 kita mulai folder baru hari ini.” → tidak.

#### 65–95 · Concept + mini · C2–C5

Transfer: spek, AC, lapisan HTML/CSS/JS, regresi. S2 akan memakai itu pada halaman yang **lebih sering berubah**. Mini: tulis 3 kemampuan + 1 target di kertas/jurnal (belum arsip).

#### 95–120 · I do · C2–C3

Checklist arsip di layar. Satu file tidak ada → tulis “tidak ada”, jangan generate spek palsu.

#### 120–165 · Practice · C3–C6

Siswa isi jurnal + arsip di folder project. Guru keliling: “bukti file mana?” Menit 150: yang jurnal masih kosong, duduk 5 menit dengan 4 outcome sebagai menu, pilih 3.

#### 165–180 · Reflect · C5

Exit. Compass: masalah sebelum solusi tetap berlaku di S2. Satu kalimat bersama opsional, bukan tepuk ranking.

### Diferensiasi

**Jurnal macet:** mulai dari outcome 2 atau 3 (halaman / klik), baru nalar.
**Semua file hilang:** tulis jujur di arsip; jurnal dari ingatan P33 + satu file yang tersisa.
**Ingin coding:** “itu target S2, bukan tugas menit 140.”
