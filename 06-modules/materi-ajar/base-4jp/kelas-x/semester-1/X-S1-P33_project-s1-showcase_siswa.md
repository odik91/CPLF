Hari ini **panggung**, bukan bengkel. Tidak coding. Tidak live-fix. Tidak ranking “paling keren.”

**Catatan skill:** folder `p33-showcase` **bukan** project baru. Tidak ada HTML/CSS/JS untuk dikerjakan. Yang ditunjuk adalah **project S1 milikmu** (P23–P32). Salin lembar ke folder itu.

## Skrip 4 menit

Salin [kartu-presentasi.md](./skill-js/p33-showcase/kartu-presentasi.md). Isi dari `spek.md` + kartu status P32.

| Slot | Waktu | Yang kukatakan / kutunjukkan |
|---|---|---|
| Masalah | 40 dtk | Pengguna + masalah (bukan “ini web kantin keren”) |
| Mengapa | 40 dtk | Kenapa solusi ini; apa yang **tidak** kutambah |
| Demo | ~80 dtk | Satu (atau dua) klik AC — sebut nomor AC |
| Gap | ~50 dtk | Kartu status: lulus / bugfix / gap jujur |
| Tanya | ~30 dtk | Jawab 1 pertanyaan audiens |

## Audiens

Salin [lembar-audiens.md](./skill-js/p33-showcase/lembar-audiens.md). Tonton ≥ 2 demo. Tulis **1 pertanyaan bernalar** (mengapa / bukti / AC), bukan “bagus.”

| Boleh | Jangan |
|---|---|
| “AC 5: setelah klik, teks apa yang kelihatan?” | “Keren.” / “Warna kurang.” |
| “Gap di kartu disebut atau tidak?” | Membuka editor teman |
| “Mengapa tidak form?” | Membandingkan “punya aku lebih…” |

## Trap

- Rapikan CSS saat antre.
- Sembunyikan gap lalu kaget ditanya.
- Klik semua tombol tanpa menyebut AC.
- “Nanti saya perbaiki di sini sekarang.”

## Checklist kelas

- [ ] Presentasi ≤ 4 menit
- [ ] Lembar audiens ≥ 2 demo
- [ ] Editor tertutup
- [ ] Tanpa live-fix / tanpa ranking
