## Setup cepat

1. Salin folder `skill-html/` ke komputermu (lihat langkah lengkap di bacaan).  
2. Buka `index.html` di browser.  
3. Kerjakan file 01 → 08 berurutan (copy-paste atau ketik ulang).  
4. Halaman milikmu buat di folder terpisah `project/` (jangan timpa contoh).
