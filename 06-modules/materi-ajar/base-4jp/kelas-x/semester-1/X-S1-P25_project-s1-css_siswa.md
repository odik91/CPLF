## Lima aturan minimal

1. `body`: font + `line-height` + warna teks/latar  
2. `header, main, footer`: `max-width` ~40rem + `margin: 0 auto` + `padding`  
3. Jarak antar `section` (`margin` / `padding`)  
4. `h1` / `h2` lebih besar atau lebih tegas dari `p`  
5. `button`: `padding`, `font: inherit`, kontras

Flex: hanya jika ada `nav` dan butuh item berjajar.

## AC keterbacaan

- [ ] File CSS terpisah dan tertaut  
- [ ] Teks tidak menempel tepi  
- [ ] Section terpisah jelas  
- [ ] Judul menonjol  
- [ ] Tombol kelihatan tombol
