## 4. Alur (180 menit)

```text
Orientation → Guru demo generate 1×
  → Kamu generate (prompt sama sekelas)
  → Gallery bandingkan
  → Deadlock “mana yang benar?” (parkir)
  → Kenali tag HTML (baca, jangan perbaiki)
  → 3 pertanyaan penasaran → Exit
```

---

## 5. Prompt seragam (salin apa adanya)

```text
Buatkan satu file HTML lengkap untuk company profile usaha:
"Warung Mie Sehat MA Al-Hikmah".

Isi halaman:
- nama usaha & tagline
- tentang kami (2–3 paragraf)
- daftar produk/menu (minimal 4 item)
- jam buka & kontak
- footer sederhana

Gunakan HTML semantik dasar. Jangan pakai framework. Satu file saja.
```

Simpan file hasil di folder projectmu sebagai **bukti proses**.
