# Skill CSS — File Contoh

Bacaan lengkap: [../00_Bacaan_Panduan_CSS.md](../00_Bacaan_Panduan_CSS.md)

## Setup cepat

1. Salin folder `skill-css/` ke komputermu (sejajar `skill-html/` dan `project/`).  
2. Buka `index.html` di browser.  
3. Tiap nomor = pasangan `.html` + `.css` (nama sama, folder sama).  
4. Kerjakan 01 → 07. Jangan timpa folder `project/` milikmu.
