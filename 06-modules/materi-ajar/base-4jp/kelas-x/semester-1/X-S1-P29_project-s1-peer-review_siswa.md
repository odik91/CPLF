Hari ini **bukan** ngoding. Kamu jadi **reviewer** (uji spek teman) dan **pemilik** (catat antrian untuk P30).

## Dua peran

| Sebagai reviewer | Sebagai pemilik |
|---|---|
| Buka `spek.md` teman + halaman di browser | Serahkan spek + halaman; tutup editor |
| Uji urutan: HTML → CSS → JS1 → JS2/polish → regresi | Diam kecuali diminta klarifikasi AC |
| Isi lembar: AC · L/G · bukti · lapisan | Terima lembar; jangan membela dengan “itu sengaja” tanpa baris spek |
| Jangan buka `script.js`, jangan edit file | Tulis rencana revisi 1–3 item |

## Bahasa bukti

| Jangan | Pakai |
|---|---|
| “Bagus.” / “Kurang keren.” | “AC 2 lulus: tiga section, masing-masing ada `h2`.” |
| “Tombolnya aneh.” | “AC 5 gagal: setelah klik, teks masih … ; spek minta …” |
| “Punya aku lebih lengkap.” | (bukan temuan — coret) |

Contoh lengkap: [contoh-umpan-balik.md](./skill-js/p29-peer-review/contoh-umpan-balik.md)

## Trap

- Review tanpa baca spek.
- Kamu yang mengklikkan halaman sendiri “biar teman cepat.”
- Teman membuka `script.js` dan mengetik.
- Mengubah AC supaya temuan hilang.
- Lembar kosong, pujian lisan.
