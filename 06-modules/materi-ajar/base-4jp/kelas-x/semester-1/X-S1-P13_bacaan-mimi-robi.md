## Adegan 1 — tiga kartu

Guru mengangkat:

```javascript
"12"
12
true
```

Robi:

> “Yang pertama dan kedua sama-sama dua belas.”

Aku:

> “Yang pertama **teks** yang memakai kostum angka. Yang kedua angka yang bisa berhitung.”

`typeof` membuka identitas:

```javascript
typeof "12" // "string"
typeof 12   // "number"
typeof true // "boolean"
```

## Plot twist — 10 + 2 = 102

Robi menulis:

```javascript
"10" + 2
```

Konsol menjawab:

```text
"102"
```

> “Matematika rusak!”

> “Tidak. Input pertama adalah string. Tanda `+` menyambung teks. Jaguar P02 pulang kampung: jenis input memengaruhi output.”

## Prediksi sebelum Enter

Hari ini bukan lomba cepat menekan Enter. Tulis prediksi, baru jalankan.

| Kode | Robi menebak | Konsol |
|---|---|---|
| `7 + 5` | 12 | 12 |
| `"7" + "5"` | 12 | "75" |
| `typeof false` | "salah" | "boolean" |

Prediksi salah bukan nilai jelek. Itu peta lokasi salah paham.

## Concept

- **Nilai:** datanya.
- **Tipe:** jenis datanya.
- **Ekspresi:** kode yang menghasilkan nilai.
- **Konsol:** laboratorium untuk melihat bukti.
