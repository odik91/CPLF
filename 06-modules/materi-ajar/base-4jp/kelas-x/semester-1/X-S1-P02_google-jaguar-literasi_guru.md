## Cognitive Trap

**Asumsi:** “Google salah/bodoh” bila hasil ≠ niat.  
**Aman:** Puji observasi; challenge **input** kurang spesifik + share tanpa baca.

## Guiding Questions

1. Apa **input persis** yang kita beri mesin?  
2. Apa yang berubah saat **satu kata** ditambah?  
3. Bagaimana membuktikan fakta #1 (**2 sumber**)?

## Props / Fallback

- Browser mode aman · proyektor · worksheet kertas cadangan  
- Offline: screenshot siap pakai; sumber kedua dari buku paket  

## Exit Ticket

1. Satu strategi keyword pribadi  
2. Satu sumber terpercaya topik MA  
3. *(opsional)* Kenapa hasil #1 ≠ fakta #1  

## Formatif

**REA**, **OBS**

## Catatan Guru

Scaffold live search **wajib** sebelum siswa search. Ketik, jangan paste. Rotasi varian `apple`/`MA` antar kelas paralel.

## B. Materi pendukung (lengkap)

> **RAHASIA GURU**

### 1. Pengetahuan yang dikuasai guru

**IPO:** output = f(kata yang diketik). Bukan mind reader.

| Input | Bias |
|-------|------|
| `jaguar` | campuran mobil/hewan/olahraga |
| `jaguar animal` / `jaguar macan` | biologi |
| `jaguar car` | otomotif |

Niat ≠ kata di kotak. Hasil #1 ≠ fakta #1. Minimal 2 sumber independen.  
Pengayaan 4JP: catat proses di `cari.html` (bukan kuliah CSS).

### 2. Recall spiral

| Tanya | Inti |
|-------|------|
| P01: batas masalah? | Sengaja dikerjakan vs tidak |
| P01: trap app? | Solusi prematur |
| Sebelum search, apa yang jelas? | Pertanyaan, konteks, keyword awal |

### 3. Etika penyampaian

| Aturan | Penerapan |
|--------|-----------|
| No copas | Jangan kirim keyword/screenshot “jawaban” guru |
| Live modeling | Ketik `jaguar` karakter demi karakter |
| Per query | TTS: Tebak → Tanya input → Spelling |
| Practice | Keyword **siswa** + HTML |

### 4. Materi inti

Urutan demo: `jaguar` → `jaguar animal` → `jaguar macan` → (opsional) fakta habitat + 2 tab sumber.

**Worksheet siswa (lalu HTML):** pertanyaan 1 kalimat · 3 keyword · screenshot/catatan · sumber kedua · beda #1 vs #3.

**Transfer:** clickbait = keyword emosional; prompt AI singkat = preview P03.

### 5. Skrip live (180')

```text
[0 — Orientation 0–10]
"Minggu lalu: batas masalah. Hari ini: mesin hanya ikut INPUT."
Compass + 1 siswa share batas P01 (30 detik).

[1 — Scaffold 10–25]
Ketik j-a-g-u-a-r perlahan. "Belum Enter — prediksi: mobil, hewan, campuran?"
Enter. Reaksi. Tambah " animal". "Apa berubah? Siapa 'salah'?"
We do: kelas usul kata ketiga.

[2 — Experience 25–50]
Opsional jaguar macan / habitat.
Setiap query: prediksi dulu → Enter → bandingkan.
Siswa boleh ikut search setelah scaffold selesai.

[3 — Trap 50–65]
Ucapkan sengaja: "Google bodoh — tidak sesuai maksud saya."
Arahkan: input vs niat di kepala — sama atau beda?

[4 — Clarify 65–80]
Ambil 1 fakta dari hasil. Tab 2: sumber lain.
"Hasil #1 belum fakta. Apa sama? Apa beda? Mana lebih kredibel?"

[5 — Concept 80–95]
Papan: output = f(input) · keyword · verifikasi.
Transfer: clickbait; prompt AI = input (preview P03, belum generate panjang).

[6 — Transisi 95–105]
Buka editor. Folder P01.

[7 — Scaffold praktik 105–120]
I do ketik kerangka cari.html (lihat modul): h1, pertanyaan, ol 3 keyword, fakta+2 sumber.
"Isi nanti punya kalian — bukan jaguar."

[8 — Practice 120–165]
Topik tugas MA nyata. 3 keyword + sumber kedua → tulis di HTML.
Keliling: tolak styling lama; fokus isi.
TTS singkat per pasangan.

[9 — Exit 165–180]
Exit ticket + preview P03.
```

### 6. Pseudo-algoritme buruk (baca bersama)

```text
MULAI
  INPUT: kata_kunci = "jaguar"
  CARI di mesin
  AMBIL hasil_baris_1
  KIRIM ke grup_WA tanpa baca
SELESAI
```

| Tanya | Kunci |
|-------|-------|
| Langkah paling berbahaya? | KIRIM tanpa baca |
| Hilang sebelum CARI? | Perbaiki keyword + verifikasi |
| INPUT = "MA"? | Ambigu (madrasah / gelar / …) |
| Hubung P01? | Share prematur = solusi prematur |

### 7. Praktik mandiri

- 3 keyword + HTML catatan  
- 1 kalimat strategi keyword  
- 1 sumber terpercaya konteks MA  

### 8. Kesalahan umum

| Siswa | Guru |
|-------|------|
| Pertanyaan panjang ala chatbot di Google | Search keyword “sudah jadi” dari slide |
| Snippet #1 = fakta | Tidak demo 2 sumber |
| Screenshot milik guru | Akun pribadi histori aneh |
| “Google salah” tanpa ubah input | Tutup debat terlalu cepat |
| CSS di Practice | Membiarkan — atau ikut hias bersama |

- [ ] Preview P03: prompt = input  
- [ ] File pendukung tidak ke siswa
