## Cognitive Trap

**Asumsi:** Setiap masalah butuh aplikasi/teknologi.  
**Aman:** Puji observasi masalah; challenge hanya pada lompat solusi prematur.

## Guiding Questions

1. Siapa yang benar-benar kesulitan?  
2. Apa bagian masalah yang **tidak** kita selesaikan minggu ini?  
3. Bukti apa bahwa ini masalah (bukan sekadar kesal)?

## Props / Fallback

- Sticky note · papan · editor teks  
- Offline: kertas + diskusi oral; HTML diganti PR berbatas  
- Bacaan: [X-S1-P01_bacaan-mimi-robi.md](./X-S1-P01_bacaan-mimi-robi.md)

## Exit Ticket

1. Masalah yang kupilih + batasnya  
2. Satu hal yang sengaja **tidak** kuselesaikan dulu

## B. Materi pendukung (lengkap)

> **RAHASIA GURU** — jangan bagikan file pendukung utuh ke siswa.

### 1. Pengetahuan yang dikuasai guru

- **Masalah** = kondisi nyata + stakeholder, bukan sekadar “kesal.”  
- **Problem framing** = gambarkan sebelum pilih solusi.  
- **Scope** = apa yang masuk vs sengaja ditinggalkan.  
- Teknologi = **salah satu** media, bukan default.  
- Protokol: *Pahami sebelum menyimpulan.*  
- Pengayaan 4JP: framing ditulis ulang ke `index.html` (jejak berpikir), bukan “belajar HTML semantik penuh.”

### 2. Recall spiral

Pertemuan pertama — tidak ada recall CPLF. Gunakan Do Now sebagai baseline. Icebreaker opsional: “Pernah dapat tugas tapi tidak yakin diminta apa?”

### 3. Etika penyampaian

| Aturan | Penerapan hari ini |
|--------|-------------------|
| No copas | Jangan kirim template framing siap isi ke WA |
| Live modeling | Framing live di papan, baris demi baris |
| Per scope | TTS per kotak: Masalah / Siapa / Batas / Pertanyaan |
| Practice HTML | Kerangka dari framing siswa — bukan demo app |

### 4. Materi inti — template framing

| Bagian | Buruk | Lebih baik |
|--------|-------|------------|
| Masalah | “Kantin jelek” | “Antre >15 menit istirahat kelas X, 3× minggu ini” |
| Siapa | “Semua” | “Siswa kelas X; petugas kantin” |
| Batas | *(kosong)* | “Tidak ubah menu; fokus antre” |
| Pertanyaan | *(kosong)* | “Bayar lambat atau makanan keluar lambat?” |

**Hook absurd (pilih 1–2):** helikopter antre · tutup sekolah · 50 app tanpa tanya petugas.

### 5. Skrip live (180')

```text
[0 — Orientation 0–20]
Ucapkan: "Hari ini Latihan berpikir. Coding = media. Peta: lihat contoh → baru kalian coba."
Tulis: ORIENTASI → CONTOH GURU → BARU KAMU COBA
Tampil: Compass + transformasi + rule · bacaan bag. 1–3
JANGAN sticky dulu.

[1 — Scaffold teori 20–40]
Template 4 kotak. Think-aloud antre kantin (isi 4 kotak).
We do: siswa lengkapi 1 kotak bersama.
Siswa LIHAT dulu — belum sticky.

[2 — Do Now 40–50]
"Format sudah kalian lihat. Tulis 1 masalah nyata."
Kumpulkan tanpa komentar.

[3 — Hook + Experience 50–70]
Tulis 1 solusi absurd. "Kenapa gagal?"
Kelompok: siapa / batas / apa BUKAN tugas kita. Timer.
Keliling TTS per kelompok.

[4 — Trap + Clarify 70–85]
Dengar usul app → "Stop. Apa masalah sebenarnya? Butuh teknologi?"
Pahami sebelum menyimpulan. Bandingkan 2 kelompok di papan.

[5 — Concept 85–95]
Tulis 3 baris: framing · stakeholder · scope (TTS per baris).

[6 — Scaffold praktik 95–110]
I do: buat folder + index.html
  <h1>Masalah: …</h1>
  <h2>Siapa</h2><p>…</p>
  <h2>Batas</h2><p>…</p>
Think-aloud: "Ini jejak framing — belum app."

[7 — Practice 110–165]
Siswa tulis framing sendiri di halaman.
Guru keliling: tolak request "langsung bikin fitur."
Kumpulkan artefak (foto/file).

[8 — Exit 165–180]
Exit ticket + preview P02 (input mesin / jaguar).
```

### 6. Latihan membaca instruksi (papan)

```text
INSTRUKSI: "Atasi antre kantin"
A: Buat grup WA
B: Share link app
C: Selesai
```

| Tanya | Kunci |
|-------|-------|
| Mana yang mengasumsikan masalah sudah paham? | Semua |
| Stakeholder hilang? | Petugas kantin; siswa tanpa HP |
| Apa hilang sebelum A? | Definisi, batas, bukti |

### 7. Praktik mandiri

- Template framing di HTML (punya sendiri)  
- Jurnal 2 kalimat: salah solusi karena buru-buru  
- Exit ticket: masalah + batas + yang sengaja tidak dikerjakan  

### 8. Kesalahan umum

| Siswa | Guru |
|-------|------|
| Langsung usul app | Excited demo teknologi di P01 |
| Masalah abstrak | Mengisi template untuk siswa |
| Batas kosong | Evaluasi ide solusi terlalu dini |
| Stakeholder = semua | Skip Orientation/Scaffold |
| Bingung tanpa contoh | Asumsi siswa = SWE |

### 9. Checklist exit guru

- [ ] Compass + transformasi  
- [ ] Scaffold sebelum sticky/kelompok  
- [ ] Live modeling papan  
- [ ] Trap “solusi = app” jalan  
- [ ] Practice HTML kerangka framing  
- [ ] Exit ticket terkumpul  
- [ ] Tidak bagikan file pendukung ke siswa  
- [ ] Preview P02
