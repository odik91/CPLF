| Item | Isi |
|------|-----|
| Transformasi | Bisa generate = sudah bisa → deadlock & penasaran (bukan malu) |
| Durasi | **180'** · impact/gallery/trap + touch coding kenali tag |
| Wajib | Prompt **seragam** · gallery · deadlock **tanpa** debug |
