## Tujuan

Mengisi `index.html` agar **spek terbaca dari HTML**, tanpa mengandalkan CSS.

## Dari spek ke bagian

| Poin spek | Tag / `id` di HTML | Sudah? |
|---|---|---|
| Judul halaman | `h1` + `<title>` | |
| Section 1 | `section` + `h2` | |
| Section 2 | `section` + `h2` | |
| Section 3 (jika ada) | `section` + `h2` | |
| Pesan awal | `id` sesuai spek | |
| Tombol fitur 1 | `button type="button"` + `id` | |
| Elemen fitur 2 | `id` / catatan di spek | |

## Checklist lulus HTML

- [ ] `header` / `main` / `footer`  
- [ ] Satu `h1`  
- [ ] 2–3 `section` + `h2`  
- [ ] Konten nyata (bukan placeholder)  
- [ ] `id` tombol/pesan = `spek.md`  
- [ ] Belum menilai “sudah bagus warnanya”

## Trap

- Jangan ganti `id` tanpa mengubah spek.  
- Jangan habiskan jam untuk `style.css`.  
- Jangan copy contoh kantin jika brief-mu A atau C.
