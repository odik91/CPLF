# P33 — Kartu presentasi + lembar audiens

Folder ini **bukan** artefak baru dan **bukan** halaman HTML untuk dikerjakan.

Ada dua isi:

1. `kartu-presentasi.md` — **salin ke folder project S1 milikmu**. Isi dari `spek.md` + kartu status P32.
2. `lembar-audiens.md` — isi saat menonton demo teman (≥ 2).
3. `contoh-skrip.md` — dibaca di kelas; jangan disalin sebagai cerita palsu.

Yang ditunjuk di panggung adalah **project yang sama** (P23–P32). Jangan menimpa projectmu. Jangan coding hari ini.

## Pakai lembar

1. Isi kartu presentasi **sebelum** gelombang (tanpa editor).
2. Browser terbuka pada `index.html` project sendiri saat giliranmu.
3. Timer 4 menit: masalah · mengapa · klik AC · gap.
4. Saat orang lain tampil: tutup editor, isi lembar audiens.
