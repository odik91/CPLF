# Contoh umpan balik P29

Bukan temuan milikmu. Untuk membedakan kalimat spek vs selera.

## Ditolak (selera / kosong / bandingkan)

- “Bagus.”
- “Kurang keren.”
- “Warnanya aneh.”
- “Punya aku lebih lengkap, tambah saja satu tombol.”
- “Modernin dikit.”

## Dipakai (nomor AC + bukti + lapisan)

- “AC 1 lulus: ada `header`, `main`, `footer`.”
- “AC 2 gagal: section daftar menu tidak punya `h2`; langsung `<ul>`. Lapisan HTML.”
- “AC 3 gagal: teks pucat di latar krem, baris melebar penuh layar. Spek minta lebar terbatas dan kontras. Lapisan CSS.”
- “AC 5 lulus: sebelum klik `#pesan` = ‘Belum dicek…’; setelah klik = ‘Mie Sehat tersedia.’”
- “AC 6 gagal: klik Ganti sorotan mengubah `#pesan`, `#sorotanCadangan` tetap ‘Belum ada sorotan cadangan.’ Lapisan JS.”
- “Regresi AC 5 gagal setelah klik tombol cadangan: teks menu tertimpa.”

## Opini — boleh dicatat, tidak wajib P30

- “Kalau spek nanti minta, warna tombol bisa lebih kontras.”
- “Nav loncatan antar section tidak ada di spek ini, jadi bukan temuan.”
