# skill-js — Latihan JavaScript Vanilla

Folder ini menyimpan file latihan yang dapat dijalankan tanpa HTML/DOM terlebih dahulu.

## Menjalankan

1. Salin file latihan yang sesuai ke folder proyekmu, misalnya `js-dasar`.  
2. Buka terminal di folder tersebut.  
3. Jalankan `node nama-file.js`, jika Node.js tersedia.  
4. Jika Node.js belum tersedia, salin eksperimen satu per satu ke Console browser.

Selalu prediksi hasil, jalankan, lalu catat bukti dan alasan.
