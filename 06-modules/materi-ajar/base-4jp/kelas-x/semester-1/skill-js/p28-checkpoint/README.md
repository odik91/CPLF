# P28 — Checkpoint: lembar uji + demo gagal

Folder ini **bukan** kunci project. Ada dua isi:

1. `lembar-checkpoint.md` — salin ke folder projectmu, isi dari `spek.md` sendiri.
2. Demo kantin yang **sengaja gagal** beberapa AC — untuk latihan prediksi di kelas, bukan untuk disalin sebagai karya.

## Pakai lembar

1. Salin `lembar-checkpoint.md` ke `project-s1-.../` milikmu.
2. Salin kalimat AC dari `spek.md` ke tabel.
3. Uji urutan: HTML → CSS → JS1 → JS2/polish → regresi.
4. Perbaiki 1–3 gagal terpenting; uji ulang; jangan menambah fitur.

## Demo (guru + prediksi kelas)

Buka `index.html` di browser. Baca `spek.md` dulu. Isi lembar **tanpa** membuka `script.js`. Baru cocokkan temuan.

Jangan menimpa projectmu dengan folder ini.
