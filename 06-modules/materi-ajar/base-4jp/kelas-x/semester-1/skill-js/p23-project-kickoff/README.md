# P23 — Kerangka Project S1 Kickoff

Folder ini **kerangka**, bukan halaman jadi. Hari ini yang dikunci: masalah, pengguna, section, empat `id`, kalimat AC, dan lima bidang DoD.

## Siswa

1. Salin folder ini. Ganti nama, misalnya `project-s1-kegiatan` atau `project-s1-kantin`.
2. Simpan `contoh-spek-lengkap.md` sebagai referensi. Baca spek brief-mu di sana kalau suatu baris belum jelas. Jangan mengumpulkan file contoh itu.
3. Isi `spek.md`. Pilih jalur A (dua klik) atau B (satu klik, kalimat kedua saat diklik ulang).
4. Samakan `index.html` dengan tabel alamat di spek: `id`, teks awal `#pesan`, label `#tombolUtama`. Jangan menambah tombol kedua hari ini.
5. Biarkan `style.css` dan `script.js` seperti ini. Keterbacaan = P25. Perilaku = P26–P27.

Empat `id` yang tidak boleh berubah setelah hari ini: `pesan`, `tombolUtama`, `sorotanCadangan`, `tombolCadangan` (jalur A). Nama `section` kedua dan ketiga boleh mengikuti isimu, lalu dikunci juga.

## Guru

Siswa menyimpan `contoh-spek-lengkap.md` di folder mereka dan membukanya saat macet. Yang dikumpulkan tetap `spek.md` milik masing-masing. `contoh-spek-kantin.md` adalah versi ringkas brief B, kalimatnya sama dengan halaman contoh P24–P27.
