# P25 — Contoh pola CSS keterbacaan

HTML mengikuti contoh P24 (brief kantin). CSS menunjukkan **aturan baca**, bukan palet wajib.

1. Bandingkan dengan `p24-html-struktur/style.css` yang minim.  
2. Salin *jenis* aturan ke projectmu; ganti warna sesuai spek.  
3. Jangan menimpa HTML project hanya agar class contoh cocok — pakai selector elemen/`id` milikmu.
