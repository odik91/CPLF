## Siklus wajib (ulang untuk tiap item)

```text
Pilih item antrian → ubah sekecil mungkin (satu lapisan)
  → uji AC itu di browser → uji regresi fitur 1 → isi log
  → baru item berikutnya
```

Prioritas 1 **wajib** selesai-atau-jujur-gagal. 2 dan 3 hanya jika 1 lulus.

## Antrian kosong?

Jangan menambah tombol/fitur. Uji regresi sekali lagi. Isi log: “tidak ada item spek.” Siap P31.

## Trap

- Kerjakan item 3 dulu karena “lebih kelihatan.”
- Tiga file sekaligus, baru tes.
- Opini peer “sekalian.”
- Generate ulang halaman.
- Hapus baris AC yang gagal.
