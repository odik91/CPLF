## Protokol debug

1. Reproduksi gejala.  
2. Baca pesan dan baris.  
3. Tulis satu hipotesis.  
4. Ubah paling kecil.  
5. Jalankan ulang.  
6. Cek output target.

## Laporan debug

| Bug | Gejala / pesan | Bukti baris | Hipotesis | Perubahan kecil | Hasil test ulang |
|---|---|---|---|---|---|
| A syntax | | | | | |
| B reference | | | | | |
| C logic | | | | | |

## Setup

1. Salin [p20-debug-bug.js](./skill-js/p20-debug-bug.js) ke `js-dasar`.  
2. Jalankan `node p20-debug-bug.js` (perbaiki satu blok per kali) atau Console browser.  
3. Hanya setelah laporan selesai, cek [solusi](./skill-js/p20-debug-solusi.js).  
4. Komentar hanya DEFINISI/GUIDE.

## Trap

- Jangan mengubah banyak baris sekaligus.  
- Jangan menyalin solusi sebelum punya hipotesis.  
- Kode yang berjalan belum tentu benar; cek output target.

## Kriteria penerimaan

- [ ] Tiga jenis bug diperbaiki  
- [ ] Hipotesis ditulis sebelum perbaikan  
- [ ] Output diuji ulang  
- [ ] Tanpa DOM/event/form
