## B. Pendukung mengajar

### Persiapan

- Hitung siswa. ≤16 satu lingkaran; 17–32 **dua stasiun**; >32 tiga stasiun.
- Timer terlihat (ponsel/papan). 4:00 angkat tangan.
- Cetak/salin `kartu-presentasi.md` dan `lembar-audiens.md` ke folder project **sebelum** menit 85 jika jaringan lambat.
- Siapkan 1 project demo guru (boleh p32-dod **setelah** bugfix, atau project kosong-aman) untuk sketsa buruk vs baik — **jangan** menimpa project siswa.
- Kursi audiens: laptop ditutup atau ditelungkupkan saat orang lain presentasi.

### Kunci sketsa (RAHASIA sampai kelas tebak)

Lihat [materi pendukung](../../../../materi-pendukung/base-4jp/kelas-x/semester-1/X-S1-P33_project-s1-showcase.md).

### Pengetahuan di lidah

- Yang dinilai: nalar terdengar, bukan gradient.
- Gap disebut = kuat. Gap disembunyikan = rapuh saat tanya.
- “Bagus” dari audiens = belum ada bukti. Minta AC / mengapa.
- P34 jangan dicuri 15 menit terakhir.

### Recall satu kalimat

> "P32 menulis status. Hari ini kamu membacakannya di panggung. P34 baru menulis apa yang tumbuh."

### Miskonsepsi

1. Showcase = hari terakhir coding.
2. Semakin banyak klik, semakin hebat.
3. Gap = nilai jelek otomatis.
4. Audiens = juri selera.
5. Stasiun = boleh buka editor di stasiun lain.

### Etika

Tidak ranking. Tidak menunjuk “yang paling jelek.” Foto opsional dengan izin. Live-fix dihentikan satu kalimat: “Catat untuk jurnal P34, jangan diketik sekarang.”

### Skrip live

#### 0–10 · Orientation · Mengingat · C1

> "Ini panggung. Bukan bengkel. Editor ditutup setelah kartu presentasi terisi. Yang ada di browser hari ini, itulah yang ditunjukkan."

Papan: **4 menit · 4 slot · kartu status · tanpa coding.**

#### 10–30 · Scaffold · Memahami · C2

Empat slot. Tunjuk kartu status P32: domain G yang tertulis = bahan slot gap, bukan aib. Tanya: “Kalau semua L, slot gap isi apa?” → keputusan yang sengaja tidak ditambah (nav, fitur 3).

#### 30–50 · Experience · C2–C4

Guru mainkan **buruk** 60 detik. Kelas sebut apa yang hilang. Lalu **baik** 4 menit dengan timer. Siswa centang slot mana yang terisi.

#### 50–65 · Trap · Menganalisis · C4

1. Guru pura-pura buka CSS “padding 2px.” → freeze.
2. “Punya Sasa lebih ramai.” → spek Sasa bukan hakim project ini.
3. Menyembunyikan AC gagal. → audiens boleh tanya kartu status.
4. Presentasi 8 menit cerita hidup. → timer 4:00.

#### 65–95 · Concept + mini · C2–C3

Bahasa audiens: contoh di `contoh-skrip.md`. Mini: isi kartu presentasi **tanpa** editor (boleh buka spek.md + kartu status sebagai teks).

#### 95–105 · Transisi

Tutup editor. Umumkan stasiun + urutan. Siapa pertama di tiap stasiun siapkan browser (bukan VS Code).

#### 105–165 · Practice · C3–C6

Gelombang. Guru: satu tangan timer, satu tangan “satu pertanyaan jika sepi.” Menit 140: cek siapa belum presentasi — geser stasiun, jangan perpanjang jadi coding.

Jika sisa waktu: **bukan** fitur baru. Ulangi 1 demo yang skripnya kacau, 2 menit.

#### 165–180 · Reflect · C5

Exit. Preview P34: jurnal 3 kemampuan + arsip folder. “Jangan mulai S2 DOM hari ini.”

### Diferensiasi

**Cemas bicara:** izinkan kartu dibaca; tetap harus ada 1 klik AC. Jangan diganti “kirim video.”
**Kelas sangat besar:** stasiun 3; guru tidak mendengar semua — lembar audiens + kartu presentasi = bukti.
**Project rusak di menit 100:** tampilkan yang ada + sebut gap; **jangan** debug 20 menit.

### Asesmen

| Indikator | Belum | Tercapai |
|---|---|---|
| Skrip | Cerita acak / hanya klik | 4 slot |
| Waktu | > 4 menit tanpa potong | ≤ 4 menit |
| Gap | Disembunyikan / “sempurna” palsu | Disebut sesuai kartu |
| Audiens | “Keren” | ≥ 1 pertanyaan bernalar |
| Coding | Editor terbuka | Freeze |
