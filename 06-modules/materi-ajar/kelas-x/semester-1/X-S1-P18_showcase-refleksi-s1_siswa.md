_Lihat modul pertemuan._

## 2. Ringkasan konsep

- **Format showcase:** 3 menit demo + 1 menit **mengapa** (reasoning) per siswa/kelompok.
- **Kapasitas waktu:** ±8–10 presenter @ 4 menit — adjust urutan/slide gatekeeper.
- **3 pertanyaan wajib presenter:**
  1. Masalah apa?
  2. Mengapa solusi ini (bukan solusi lain)?
  3. Satu kesalahan & perbaikan?
- **Peer:** 1 pertanyaan bernalar per demo — bukan roast.
- **Guru closing (70–80 menit):** pola kuat semester + area perbaikan S2 — tanpa ranking toxic.
- **Refleksi tertulis (80–90 menit):** 3 capability CX yang tumbuh + 1 target S2.
- **Penilaian:** skor project 6 aspek + narasi — lihat rubrik project.
- **Dokumentasi:** foto/portofolio untuk S2 — rayakan proses.

## 3. Materi praktik

### Struktur presentasi 4 menit

| Menit | Isi |
|-------|-----|
| 0–1 | Masalah & konteks (siapa user, apa pain) |
| 1–3 | Demo fitur DoD — live, bukan video panjang |
| 3–4 | **Mengapa** solusi ini + 1 kesalahan & perbaikan |

### Coaching sebelum showcase (prep P17 atau 5 menit pertama P18)

**Checklist presenter:**

- [ ] Bisa jawab 3 pertanyaan wajib tanpa baca slide penuh
- [ ] Demo path **happy path** + 1 edge case jika sempat
- [ ] Siap tunjuk bukti revisi peer (ITR)
- [ ] Backup: screenshot jika live demo gagal — jelaskan gejala (OBS)

### Pertanyaan peer bernalar (contoh)

- "Langkah mana yang paling sering ROBI salah paham?" (PRJ-01)
- "Apa yang terjadi di antrian ke-11?" (PRJ-02)
- "Bagaimana kamu uji input invalid?" (PRJ-03)

### Guru synthesis (70–80 menit)

2–3 pola **kuat** + 2 area **umum perlu perbaikan S2** — contoh:

- Kuat: semakin banyak yang baca error dulu
- Perbaikan S2: validasi input, struktur file, dokumentasi

### Refleksi capability

Draft Progress Card — 3 CX capability + bukti dari semester (bukan nilai angka di kelas).

## 4. Lembar kerja / latihan

Showcase **bukan** membaca kode baris-per-baris. Gunakan snippet hanya untuk **latihan peer question** sebelum demo (opsional 5 menit):

```javascript
// Cuplikan anonim — teman latih tanya "mengapa"
if (harta >= nisab && haul >= 1) {
  console.log("Wajib zakat");
}
```

| Pertanyaan peer (coaching) | Kunci |
|----------------------------|-------|
| Tanya bernalar? | "Mengapa AND, bukan OR?" / "Bagaimana nisab didefinisikan?" |
| Bukan | "Salah syntax" di showcase |
