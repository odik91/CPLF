## Pengetahuan Guru

Showcase S5 = **penutup semester** + artefak portofolio S6 — bukan lomba akurasi.

| Komponen presentasi | Wajib | Bobot penilaian |
|---------------------|-------|-----------------|
| Masalah & data | Konteks MA nyata | OBS, REA |
| Demo prediksi live | 1 sukses | TEC |
| **Demo gagal / batasan dibacakan** | **Wajib** | **Etika E1 ≥ 2** |
| Metrik jujur | N data + mitigasi | REA, COM |
| Refleksi spiral | AI ≠ chatbot only | TRF |

**Gate kelulusan project (XII):**

| Syarat | Minimum |
|--------|---------|
| DoD artefak | Model jalan + UI + dokumen batasan |
| E1 batasan & kejujuran | Level ≥ 2 |
| E1 = 1 (overclaim/sembunyikan gagal) | **Dikembalikan** — meski demo mulus |
| Kasus gagal | Ditunjukkan, bukan disembunyikan |

**Format presentasi 4–5 menit:**

```text
0:00 — Masalah & untuk siapa (30s)
0:30 — Data: sumber, N, fitur (45s)
1:15 — Demo prediksi sukses (1m)
2:15 — Demo prediksi GAGAL + kenapa (1m) ← wajib
3:15 — Baca batasan + klaim terlarang (45s)
4:00 — Peer feedback rubrik ringkas (30s)
4:30 — Refleksi 1 kalimat spiral S5
```

**Simpan artefak:** repo, PDF batasan, screenshot metrik — untuk P16 portofolio S6.

## Materi Inti

### Transformasi belajar (semester)

**Dari:** "AI = chatbot pintar / akurasi di poster"  
**Ke:** "Produk = **data + model + batasan** — amanah ke pengguna."

### Timeline fasilitator (90 menit)

| Menit | Fase | Peran guru |
|-------|------|------------|
| 0–50 | Showcase | 4–5 menit/siswa · timer · catat rubrik |
| 50–65 | Peer | Feedback rubrik ringkas (2+1) |
| 65–80 | Reflect | Pleno: 3 tema semester |
| 80–90 | Closing | Preview S6 capstone + etika · simpan artefak |

### Rubrik ringkas peer (showcase — 2 menit)

| + | ? |
|---|---|
| 1 pujian spesifik (data/batasan/demo) | 1 pertanyaan tentang risiko salah prediksi |

**Larangan:** "Paling keren", bandingkan ranking akurasi.

### Refleksi pleno (65–80 menit)

Prompt di papan:

```text
1. Satu konsep S5 yang paling mengubah cara lihat "AI"
2. Satu kebiasaan jujur (metrik/batasan) yang akan dibawa ke S6
3. Satu hal yang masih sulit — OK untuk belum paham penuh
```

Guru parafrase — **tidak** sermon panjang.

### Closing S6 preview (80–90 menit)

- Capstone citra/webcam — Teachable Machine atau TF.js transfer
- Etika: consent, wajah, data siswa — [E2 Rubrik Etika](../../../../09-rubrik/09_Rubrik_Etika_AI.md)
- Portofolio: artefak S5 + changelog P16 masuk folder semester

## Alur Live Coding / Facilitator

### Persiapan

- [ ] Urutan presentasi — random atau alphabetical (hindari "terbaik terakhir")
- [ ] Timer proyektor + lembar rubrik guru per siswa
- [ ] Checklist DoD: model · UI · batasan PDF · changelog peer
- [ ] Backup offline jika demo gagal teknis — **tetap** harus tunjuk kasus gagal model (bukan cuma WiFi)
- [ ] Baca: [09_Rubrik_Project](../../../../09-rubrik/09_Rubrik_Project.md) · [09_Rubrik_Etika_AI](../../../../09-rubrik/09_Rubrik_Etika_AI.md)

### Skrip fasilitator

```text
[LANGKAH 1 — Norma 0–3 menit]
Ucapkan: "Showcase bukan lomba akurasi — yang dihargai: jujur batasan."
Tampilkan: checklist wajib (demo gagal + batasan dibacakan)
Tanya: "Siapa revisi dari P16 peer review? Sebut 1."

[LANGKAH 2 — Showcase 3–50 menit]
Timer 5 menit — warn menit 4 jika belum bagian gagal
Catat: DoD · 6 aspek · Etika E1–E4 (mental/ lembar)
Intervensi E1=1: catat "revisi wajib" — jangan malu-in di depan kelas

[LANGKAH 3 — Peer 50–65 menit]
Format 2+1 — 1 menit per presenter
Scope: pertanyaan harus tentang risiko/batasan jika memungkinkan

[LANGKAH 4 — Reflect 65–80 menit]
3 prompt pleno — sticky note atau oral round
Ucapkan: "Belum paham loss penuh — normal di MA. Paham batasan = capaian."

[LANGKAH 5 — Closing 80–90 menit]
Preview S6 2 menit
Ucapkan: "Simpan repo + batasan — dipakai lagi."
Collect artefak / konfirmasi upload
```

### Penilaian guru (setelah kelas)

1. Cek DoD — gap → feedback tertulis, bukan hanya angka
2. Skor 6 aspek + Etika AI
3. Narasi 2–3 kalimat capability (wajib rubrik project)
4. E1=1 → kembalikan dengan daftar perbaikan spesifik

### Contoh narasi capability (guru)

> "Siswa X dapat menjelaskan metrik latih dengan N konkret dan mendemo kasus gagal (REA, E1 level 3). Perlu memperdalam split train/test di S6."

## Latihan Membaca Kode / Presentasi

### Snippet — Slide buruk

```text
🚀 AI TERBAIK KELAS XII
Akurasi 98.5% — Powered by Deep Learning
Tanpa batas · Tanpa error
```

| Pertanyaan membaca | Kunci jawaban |
|--------------------|--------------|
| Red flag etika? | Overclaim · sembunyikan error · "terbaik" |
| E1 level? | **1** — revisi sebelum nilai final |
| Perbaiki judul | "Asisten tebak [masalah] — eksperimental, lihat batasan" |

### Snippet — Refleksi kuat

```text
Awal semester saya kira AI = ChatGPT.
Sekarang: tanpa data bersih dan batasan tertulis, model bisa menyesatkan wali kelas.
Saya belum paham rumus loss, tapi tahu kapan tidak boleh percaya angka akurasi.
```

| Pertanyaan membaca | Kunci jawaban |
|--------------------|--------------|
| TRF level? | 3–4 — hubung konsep ke konteks |
| COM? | Bahasa awam, jujur tentang limit pribadi |

## Praktik Mandiri

*(Showcase = aktivitas kelas — PR pasca-showcase jika E1=1)*

1. Upload artefak final ke repo/folder portofolio.
2. Revisi batasan jika feedback peer/guru.
3. Tulis refleksi 5 kalimat untuk jurnal semester.
4. Yang E1=1: demo gagal + paragraf batasan dalam 3 hari (kebijakan sekolah).

## Kesalahan Umum

| Siswa | Guru |
|-------|------|
| Slide penuh angka, demo singkat | Timer prioritaskan demo live |
| Skip bagian gagal | Stop sopan — "slot gagal dulu" |
| "Waktu habis" tanpa batasan | Extend 30s untuk baca 2 kalimat batasan |
| Peer jadi voting "terkeren" | Larangan ranking — fokus rubrik |
| Guru umumkan "juara akurasi" | **Larangan** — hargai kejujuran |
| Nilai hanya demo mulus | Pakai rubrik etika — E1 gate |
| Lupa simpan artefak S6 | Checklist collect di closing |
