# X-S1-P33 — Project S1: Showcase Reasoning

| Field | Isi |
|---|---|
| Kode | X-S1-P33 |
| Basis | **4JP** · Pertemuan **33/34** |
| Unit | X1.8 |
| Durasi | **4 JP = 180 menit** |
| Status | **Isi penuh** |
| Batas | **Presentasi reasoning + demo artefak yang ada; tanpa coding, tanpa live-fix, tanpa ranking** |

## Learning Transformation

Dari halaman yang sudah punya DoD dan kartu status → **halaman yang bisa dijelaskan**: masalah, mengapa solusi ini, satu klik AC, satu gap jujur. Showcase = panggung nalar, bukan pamer palet dan bukan bengkel.

## Capaian pembelajaran (Taksonomi Bloom revisi)

| Kode | Level | Siswa mampu … |
|---|---|---|
| **C1** | Mengingat | Menyebut slot skrip: masalah, mengapa, demo AC, gap |
| **C2** | Memahami | Menjelaskan beda showcase vs P32 (uji) vs P34 (refleksi); beda demo klik vs renovasi live |
| **C3** | Menerapkan | Menyampaikan 4 menit sesuai kartu presentasi + kartu status P32 |
| **C4** | Menganalisis | Sebagai audiens: membedakan klaim, bukti klik, dan opini “keren” |
| **C5** | Mengevaluasi | Memilih 1 pertanyaan bernalar; menilai apakah gap dijelaskan atau disembunyikan |
| **C6** | Mencipta | Jejak kartu presentasi terisi (siap diarsip P34) |

**Fokus:** C3–C5 · **Puncak:** C5 · Refleksi S1 → **P34**

## Skrip 4 menit (inti)

| Menit | Slot | Isi |
|---|---|---|
| 0:00–0:40 | Masalah | Siapa pengguna, masalah apa (dari spek) |
| 0:40–1:20 | Mengapa | Kenapa solusi ini, bukan fitur 3 / bukan brief lain |
| 1:20–2:40 | Demo | Satu klik AC (fitur 1); jika ada fitur 2, satu klik lagi |
| 2:40–3:30 | Gap / keputusan | Kartu status: lulus / bugfix / gap jujur |
| 3:30–4:00 | Tanya | Satu pertanyaan audiens bernalar |

Timer dipotong. Lebih dari 4 menit = guru angkat tangan, lanjut.

## Format kelas (sesuaikan jumlah)

| Jumlah presenter | Pola |
|---|---|
| ≤ 16 | Satu lingkaran, guru timer |
| 17–32 | **2 stasiun** paralel (masing-masing ~8–16 giliran); guru rotasi |
| > 32 | 3 stasiun; tiap siswa presentasi di stasiun, lembar audiens diisi 2 demo |

Yang tidak sedang presentasi **wajib** isi lembar audiens (bukan buka editor).

| Bukan | Melainkan |

| P34 dipindah ke hari ini | Showcase dulu; jurnal S1 besok |

## Konsep inti

| Istilah | Arti hari ini |
|---|---|
| **Showcase** | Menunjukkan halaman + alasan, dengan waktu terbatas |
| **Reasoning** | Mengapa solusi ini, bukan hanya “sudah jadi” |
| **Kartu presentasi** | Naskah 4 slot — disalin dari spek + kartu status P32 |
| **Lembar audiens** | 1 pertanyaan / 1 bukti per demo yang ditonton |
| **Freeze coding** | Editor ditutup dari menit 95 sampai bel |

## Cognitive Trap

- Membuka VS Code “sebentar rapikan padding” saat antre.
- Menyembunyikan gap lalu kaget saat ditanya.
- Audiens hanya bilang “bagus” / “keren”.
- Presenter mengklik semua tombol tanpa menyebut AC.
- Guru membandingkan palet dua project di depan kelas.

## Guiding Questions

1. Masalah di spek masih yang kuceritakan, atau sudah bergeser ke “halaman cantik”?
2. Klik yang kutunjukkan: AC nomor berapa?
3. Gap di kartu status: kusebut atau kuhapus dari cerita?
4. Pertanyaan audiens: nalar (mengapa / bukti) atau selera?
5. Setelah 4 menit: apa yang orang lain **paham**, bukan hanya **lihat**?

## Kriteria penerimaan

- [ ] Kartu presentasi terisi 4 slot (tanpa coding hari ini)
- [ ] Presentasi ≤ 4 menit: masalah · mengapa · klik AC · gap/keputusan
- [ ] Lembar audiens: ≥ 2 demo ditonton + 1 pertanyaan bernalar
- [ ] Editor tertutup selama gelombang showcase
- [ ] Tanpa live-fix / tanpa ranking / tanpa fitur baru

## Exit Ticket

1. Satu kalimat masalah projectku: …
2. Satu klik AC yang kutunjukkan: …
3. Gap yang kusebut (jujur) / “tidak ada, kartu hijau”: …
4. Satu pertanyaan bernalar yang kuterima atau kutulis untuk teman: …

## Formatif

**Menerapkan · C3** · **Mengevaluasi · C5** — nalar terdengar, bukan ranking visual.

## Catatan Guru

Nilai skrip dan kejujuran gap, bukan “wow”. P34 = jurnal + arsip; jangan dipaksa masuk 15 menit terakhir. Foto layar (opsional) untuk portofolio — bukan lomba screenshot.
