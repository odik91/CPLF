# Taksonomi Bloom Revisi (C1–C6) — Base 4JP

**Version:** 0.1  
**Berlaku:** materi `base-4jp` (modul · guru · siswa).  
**Beda dari** elemen CP Merdeka (`BK` / `AP` / `AD` / `LD`) — itu tetap di metadata modul sebagai **Elemen CP Merdeka**.  
**Capaian Bloom** = level kognitif pertemuan (apa siswa *mampu lakukan* hari itu).

---

## Kode wajib

| Kode | Level (revisi Anderson & Krathwohl) | Kata kerja tipikal (contoh) |
|------|-------------------------------------|-----------------------------|
| **C1** | Mengingat | menyebut, mengingat, mendaftar |
| **C2** | Memahami | menjelaskan, membedakan, merangkum |
| **C3** | Menerapkan | menggunakan, menjalankan, menulis (mengikuti pola) |
| **C4** | Menganalisis | membandingkan, memecah, menemukan asumsi/penyebab |
| **C5** | Mengevaluasi | menilai, mencentang kriteria, memutuskan dengan alasan |
| **C6** | Mencipta | merancang, menyusun artefak baru (spek/halaman/algoritma milik sendiri) |

---

## Cara pakai di materi

1. Setiap modul/guru/siswa punya bagian **Capaian pembelajaran (Bloom C1–C6)**.  
2. Kolom **Bloom** di timeline: satu kode fokus fase itu (boleh `C2–C3` jika rentang sempit).  
3. Jangan memaksakan C6 setiap pertemuan — puncak disesuaikan beban.  
4. Ke siswa: sebut **nama level** + kode (`Memahami · C2`), jangan kode alone tanpa arti.

### Pemetaan kasar fase CPLF → Bloom

| Fase Compass | Bloom tipikal |
|--------------|---------------|
| Orientation / recall | C1 |
| Scaffold / Concept | C2 |
| Experience | C2–C3 |
| Trap + Clarify | C4 |
| Practice (ikuti model) | C3 |
| Peer uji / kriteria | C5 |
| Artefak baru milik siswa | C6 (ringan di awal S1) |
