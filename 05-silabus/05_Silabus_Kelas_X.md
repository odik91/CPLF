## Semester 2 — Web sebagai Ekspresi Logika

**Elemen CP:** AP, LD, BK  
**MM utama:** MM-06–10, MM-14–15 (awal), penguatan MM-00  

### Unit tema

| Unit | Tema | Cognitive Trap (arah) | Konsep yang lahir | Media / skill | Capability | Bukti belajar |
|------|------|------------------------|-------------------|---------------|------------|---------------|
| X2.1 | Mengapa web? | Web = hafalan tag | Representasi visual dari pikiran | HTML struktur | CX-T1 | Halaman semantik sederhana |
| X2.2 | Bentuk & hierarki visual | “Asal cantik” tanpa struktur | CSS sebagai aturan presentasi | CSS dasar | CX-T1 | Layout terbaca |
| X2.3 | Logika bertemu halaman | Halaman mati tanpa perilaku | JS di browser | DOM sangat dasar, event klik | CX-T2–T3 | Interaksi 1–2 kontrol |
| X2.4 | Form & keputusan | Input diterima mentah | Validasi sisi klien sederhana | Form, if | CX-T3, B4 | Form + pesan error jelas |
| X2.5 | Mengelompokkan data di UI | Data tercerai-berai | Array/object di UI | List rendering sederhana | CX-T3 | Daftar dinamis mini |
| X2.6 | Identitas & state sederhana | Bingung “data dari mana” | State di memori halaman | Object state mini | CX-T2 | Fitur tambah/ubah item |
| X2.7 | Project S2 + presentasi | Produk tanpa alasan | Transfer + komunikasi | HTML/CSS/JS | CX-K1–K2, C1 | Demo + mengapa desain begitu |
| X2.8 | Refleksi tahun X | — | Spiral: apa yang berubah dalam cara berpikir | Portofolio 2 artefak | Semua CX | Refleksi tertulis + showcase |

**Contoh project S2:** [PRJ-X-S2-01 … 04](../08-project/08_Project_Bank_Index.md) (zakat UI, jadwal, absensi mini, profil ekskul).

**Asesmen S2:** artefak berjalan + penjelasan reasoning + perbaikan setelah review teman/guru.
