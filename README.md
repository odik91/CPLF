# CPLF — Constructive / Contextual Problem Learning Framework

**Versi:** 0.1 · **Konteks:** Madrasah Aliyah · Mapel **Multimedia** (pemrograman web / JavaScript)  
**Kurikulum:** Kurikulum Merdeka — elemen CP Informatika Fase E–F, diadaptasi ke produk web & AI di browser

---

## Apa itu CPLF?

CPLF adalah **framework pembelajaran** untuk menumbuhkan **problem solver**, bukan penghafal sintaks.

HTML, CSS, JavaScript, dan TensorFlow.js dipakai sebagai **media** belajar. Yang dibangun jangka panjang: cara bernalar, mental model, dan tanggung jawab atas solusi — termasuk penggunaan AI yang jujur dan etis.

> Kita tidak sedang mencetak web developer. Kita membantu remaja membangun identitas sebagai orang yang mampu menghadapi masalah baru tanpa takut belajar hal baru.

**Prinsip bernalar (moto kelas):**  
*Jangan cepat percaya. Jangan cepat menolak. Pahami dulu.*

---

## Inti metode (satu gambar)

```text
Experience → Observe → Question → Clarify → Reason
→ Concept → Practice → Reflect → Transfer
```

Setiap unit idealnya punya **Cognitive Trap** — membongkar asumsi siswa tanpa mempermalukan.

**Lapisan pembelajaran:**

```text
Identity → Prinsip Bernalar → Mindset → Mental Model → Skill → Tool
```
