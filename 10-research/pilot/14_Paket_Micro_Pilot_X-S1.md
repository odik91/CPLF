# Paket Micro-Pilot — Kelas X Semester 1 (3 Pertemuan)

**Versi:** 0.1  
**Durasi total:** 3 × 90 menit ≈ 1 minggu efektif  
**Tujuan:** Uji DNA CPLF minimum sebelum komit 18 pertemuan

---

## Mengapa paket ini?

Tiga pertemuan ini saling **independen cukup** untuk micro-pilot, tapi **representatif** komponen inti:

```text
P01  Identity & problem framing     (tanpa syntax)
P04  Cognitive Trap → algoritma     (experience-heavy)
P13  Error = informasi              (culture + sedikit JS)
```

Urutan **P01 → P04 → P13** disarankan. Jika semester sudah berjalan, P13 bisa digeser setelah P08–P10 (setelah if/loop).

**Indikator lapangan OK:**

- Siswa tidak panik saat error muncul

**Watch-out:** Jika belum ada JS sebelumnya, fokus demo guru + pair reading error message — jangan forced coding panjang.

## Persiapan H-1 (ketiga pertemuan)

```text
□ Baca modul + materi masing-masing P
□ EXP_01 untuk P04
□ Siapkan jurnal kosong × 3
□ Checklist lab (browser, proyektor)
□ Recall: P04 butuh energi — jadwalkan bukan jam terakhir Jumat sore (jika bisa)
```
