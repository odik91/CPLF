# EXP_02_C — Poster “Menarik”

**Parent:** [EXP_02_Gambar_Rumah.md](./EXP_02_Gambar_Rumah.md)  
**Varian:** C · **Unit:** X1.3  
**Durasi:** 8 menit · **Props:** contoh poster acara

## Learning Transformation

Sama parent: ambiguitas brief.

## Experience

**“Buat poster tabligh akbar menarik.”**

Beberapa full foto, beberapa tipografi saja, beberapa terlalu ramai tidak terbaca jarak jauh.

## Cognitive Trap

“Menarik” ≠ spesifikasi **audience, medium (cetak/WA), CTA, informasi wajib**.

## Guiding Questions

1. Poster untuk ditempel di dinding atau di-share WA?
2. Info wajib apa (waktu, tempat, kontak)?
3. Dari 3 meter masih terbaca?
4. Tulis brief 7 poin sebelum desain.
