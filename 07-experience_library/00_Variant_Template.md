# Template Varian Experience

**Cara pakai:** Salin untuk varian baru. Nama file: `EXP_{NN}_{A|B|C|...}_{Nama_Kasus}.md`

---

## Metadata

| Field | Isi |
|-------|-----|
| Parent | EXP_XX (induk) |
| Varian | A / B / C / … |
| Judul kasus | |
| Unit / MM / Capability | *sama dengan parent kecuali ada alasan* |
| Durasi | 8–15 menit |
| Props | |

## Learning Transformation

*Salin dari parent — harus identik.*

## Experience (skenario unik varian ini)

*Tulis skenario spesifik. Ini satu-satunya bagian yang wajib benar-benar beda antar varian.*

## Cognitive Trap

*Salin inti trap dari parent — asumsi yang sama, konteks berbeda.*

## Guiding Questions

3–5 pertanyaan — sesuaikan detail kasus, pola tetap.

## Clarification

Singkat — bisa merujuk parent jika identik.

## Concept · Practice · Reflection · Transfer

Jika identik dengan parent: tulis satu baris + link ke file induk.  
Jika ada nuansa baru: tulis delta saja.

## Catatan Rotasi Kelas

- Kelas mana sudah pakai varian ini (isi manual guru)
- Jangan ulang varian yang sama ke kelas paralel di tahun ajaran sama

## Anti-Pattern

- Membocorkan varian ke kelas lain sebelum experience
- Mengganti trap inti hanya demi lucu — varian bukan skenario acak
