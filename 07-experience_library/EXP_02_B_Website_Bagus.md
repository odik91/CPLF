# EXP_02_B — Buat Website “Bagus”

**Parent:** [EXP_02_Gambar_Rumah.md](./EXP_02_Gambar_Rumah.md)  
**Varian:** B · **Unit:** X1.3 · **MM:** MM-23  
**Durasi:** 10 menit

## Learning Transformation

Sama parent: spesifikasi vs interpretasi subjektif.

## Experience

Client (guru): **“Buat website yang bagus untuk pengumuman kelas.”**

Siswa A: landing animasi berat. Siswa B: satu halaman teks hitam-putih. Siswa C: mirip Instagram.

Semua bilang sudah “bagus”.

## Cognitive Trap

Kata **“bagus”** bukan requirement — tidak bisa diuji benar/salah.

## Guiding Questions

1. Apa arti “bagus” untuk **pengguna** (siswa/orang tua)?
2. Ubah “bagus” menjadi 5 kriteria terukur.
3. Acceptance criteria: load < 3 detik? mobile? warna sekolah?
4. Siapa sign-off final?
