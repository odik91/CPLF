## Alur Cepat Guru

```text
Unit/Experience  →  Formatif (OBS, REA, TRF)
        ↓
Project semester →  Rubrik Project (6 aspek + DoD)
        ↓
(XI) Peer review →  Rubrik Peer
        ↓
(XII) Capstone   →  Project + Etika AI
        ↓
Akhir semester   →  Progress Card (capability)
```

## Konversi ke Nilai Sekolah (opsional)

Jika sekolah wajib angka 0–100:

| Rata level 6 aspek* | Arah huruf / deskripsi |
|---------------------|------------------------|
| 1.0 – 1.7 | Perlu bimbingan (Belum tampak–Berkembang) |
| 1.8 – 2.5 | Berkembang |
| 2.6 – 3.3 | Cakap |
| 3.4 – 4.0 | Mahir |

\*Atau rata tertimbang sesuai bobot semester di filosofi.  
**Jangan** hilangkan narasi capability di rapor proses.
